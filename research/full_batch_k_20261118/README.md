# Filtered BC whole-round timing
Turn Switch, H100, 32 fixed episodes, 16 environments in two waves, NFE 10. Prior whole-card peak at K=8 with capped candidate batches was 78.35 GiB on a 79.65 GiB card. Each policy query now packs all 16*K rows in environment-major order. Candidate zero uses the same noise across K and drives the environment. All K samples contribute to action-wise entropy. For K>1 we retain the preceding timing run's successful-trajectory filter and bounded 0/1/5 entropy weight mapping normalized across both waves; K=1 uses unit weights. Each round includes four optimizer steps with batch 128. Each K restarts the student and optimizer; one warm-up and three measured rounds.

The paired replay uses the rollout teacher before parameter synchronization, the recorded observations, and the same candidate-zero noise. It alternates K-first and 1-first queries. Replay and its observation copies are excluded from round totals. Compare the mean summed paired difference to the mean measured round time. Whole-card memory is sampled once per second; PyTorch also tracks the allocated high-water mark. See calls.json, rounds.csv, paired.csv, summary.csv and figure3.pdf.
