## 查阅与复用

- 每路的 `experiment.json` 登记模型、任务、权重和指标。`initial.yaml` 和 `current.yaml` 分别保存启动及登记时的配置，机器路径在 `paths.env.example` 中按变量列出。深圳 1 机同名登记目录保留原始配置和对应的路径表。
- `success.json` 保存逐轮训练及独立评估成功率。`metrics.csv` 含本次快照全部 TensorBoard 标量。`implementation.json` 将实际运行的核心源文件逐一对应到 Git 版本或同目录下的实现快照。
- 深圳 1 机本人 Home 的 `models/protected-eval/success-registry-20261119/g5`、`g7` 中，各自的 `checkpoints.json` 指向最佳小策略、配套基础 π0.5 和完整续训检查点。评估最佳策略时，将小策略载入相应基础模型；恢复优化器、目标网络和回放时使用完整续训点。
