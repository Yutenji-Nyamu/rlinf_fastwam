# RoboDojo · π0.5 GRPO · 倒液体渲染对照

目的为衡量 32 环境/卡时，按动作块更新画面能省多少完整训练时间，以及还保留多少可用于 GRPO 的成败差异。

| 设置 | 逐步渲染 A | 按块渲染 B |
|---|---|---|
| 初始权重、噪声种子、学习率 | 原始 π0.5，沿用 128 局配置 | 相同 |
| 采样 | 2 卡各 32 个环境，两批共 128 局，16 个八局组 | 相同 |
| 环境与模型 | 每局 400 步，每 50 步重新决策，三相机，逐步物理和成功判定 | 相同 |
| 训练渲染 | 动作之间也调用渲染器 | 省略动作块内显式渲染，决策时获取同步图像 |
| 训练后评估 | 更新一整轮后，用原渲染做 32 局独立评估 | 同一官方节奏、布局与种子 |

A、B 均从原始权重独立重跑，各自完成首轮保存及独立评估。先跑 B，再跑 A。先前一次 A 的 128 局有 10 局成功，旧版调度参数使其在检查点写出前退出；该批仅作额外的采样记录。冻结原始模型的共同基线为 6/32（标准 25 局为 5/25）。两版训练都用真实的策略采样和参数更新。各自记录 128 局的成功总数、16 组中有成有败的组数、实际执行步数和完整轮耗时。另列采样、更新、重置、渲染与物理耗时，独立评估单算。正式训练使用选定的设置从头开始。

优先速度。本轮的操作选择为 B 完整训练轮至少省时 10%，训练有成功且有混合组，按两版与基线都实际跑到的同布局比较，B 的官方评估非零且相对 A 最多低 10 个百分点（同样 32 局时可少 3 局）。配对覆盖至少 24 局。记录两版相对共同基线的变化。单轮、单种子的结果用于选配置，长期学习曲线另看正式训练。

相同动作分块下只计算模型需要的观测，有 RoboScope Kit 在 RoboTwin Easy 上的先例。Dojo 原生评估在动作块内仍取图，两版训练后的独立评估都沿用这一节奏。[RoboScope Kit §3、§5](https://arxiv.org/html/2611.03850v1) · [Dojo π0.5 评估循环](https://github.com/XPolicyLab/XPolicyLab/blob/main/policy/Pi_05/deploy.py) · [相机同步](https://github.com/RoboDojo-Benchmark/RoboDojo/blob/main/env/camera_manager/capture/render_sync.py)
