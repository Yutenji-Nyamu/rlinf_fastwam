> 以下是多人协作建议，不构成强制规范，具体以人类判断为准。

存储布局、各目录用途和共享区说明见 `/home/readme_storage_to_codex.md`。

网络和共享代理的简要说明见 `/home/readme_network_to_codex.md`。

## 存储与使用

- `nvme0` 是约 3.5 TiB 的系统盘，由 LVM 分给根目录、`/home` 和容器存储；`nvme1` 是独立数据盘，挂载为 `/data`。
- `/home` 总容量约 2.3 TiB，用户可直接在自己的家目录中放置项目、Conda/venv 环境、依赖和默认缓存。
- 每个普通用户可使用 `~/data`（链接到 `/data/<用户名>`，适合长期数据和大模型）与 `~/shared`（链接到 `/data/shared`，用于团队共享）。
- 已取消 `/scratch`。不要再引用 `~/scratch` 或 `/scratch`。
- `/home` 和 `/data` 都是多人共享总容量，目前未设置每用户磁盘配额；大规模写入前应先运行 `df -h ~ ~/data` 查看余量。
