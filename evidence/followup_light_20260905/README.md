# Historical light artifact backup

Configs, metrics, bounded logs and diagnostics only. An archive is not a claim that a run succeeded, that a diagnostic patch is validated, or that it was applied to production. Source run paths and file hashes are retained. No models, checkpoints, replay images, videos or full Ray logs. The unmerged RLT patch is a snapshot of existing dirty changes, not applied source; the original diagnostic worktree remains unchanged.
