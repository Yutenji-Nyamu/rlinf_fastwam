# Attn：47任务的轻量结果与7个执行例

2026-10-13，复用已验收的原生π0.5 B16/H50/M10记录；本次仅CPU离线分析，没有重新推理或修改训练。47任务共1504条记录、1496个不同任务/实际seed组合，858条成功。订书机、风扇、鼠标垫三个任务的96条仍暂缓，未混入结果。

## 文件与体积

- `derived/`：94个分批NPZ，共49.16 MiB；`index.json`列任务、实际seed、成功标签、原验证回执及来源。包含所有有效记录的末次去噪逐动作标量。
- `examples/`：7个执行的原始曲线、单列大图、四模态独立纵轴的加权贡献图、前后帧、H264短视频、全部10次去噪的精确标量。打开`index.html`可展开/全屏查看。
- 全量派生值加7例约64 MiB。原始Q/K约181.21 GiB、全部去噪轮分数约11.95 GiB仍留SZ3；这两个体积是已验收批次的对应文件合计，未包括历史失败尝试。模型权重、原始Q/K不上传。

## 三个量必须分开

每个动作位置读取视觉、指令、状态、动作四类来源。原始注意力先平均8个head，再平均10/14/18三层；主图使用末次去噪（第10次）。

- `E_g = H_g / log(N_g)`：在来源g内部，读取分布有多分散；N≤1或无有效质量时为NaN。
- `M_g`：原始完整注意力分布中读来源g的质量。`ME_g = M_g E_g`是未归一化加权熵。
- `C_g = M_g E_g / Σvalid M`：对总加权熵的贡献；`E_weighted = Σ C_g`。`other`不进入这四来源的聚合，原质量单独保留。

这不是四类token合在一起的联合熵。E、M、C分别回答集中程度、读多少、对聚合贡献多少；不能把E的深谷直接叫作C的深谷。

## 这批数据目前能看出什么

全部已知执行位置的读取量中位数：视觉12.30%、指令0.243%、状态11.74%、动作63.49%。动作占四来源内归一化权重的中位数为71.96%，因此总加权熵容易继承动作模态形状。各中位数独立计算，不能直接相加。

1. **抓取搬移 `place_a2b_left`**：视觉E为0.856→0.664→0.846，谷底视觉M同时上升，C变化远小于E。照片能看到抓取、提起、移向目标；只定位到chunk阶段。
2. **面包入锅 `place_bread_skillet`**：状态E出现宽低区并恢复；读取量变化使C方向不同。它是状态token的读取分散程度，不是状态预测误差。
3. **面包入篮／叠碗**：指令E有明显深谷，但指令质量很小。叠碗已知q6的E约0.739→0.208，末点指令M约1.85%，总Ew仍约0.930；录像显示叠放和松爪阶段。不能据此认定某一个h就是接触瞬间。
4. **必须保留反例**：移走扑克牌的总熵、敲块的动作熵看起来有漂亮峰，但同任务chunk位置模板可解释约69%／68%的曲线变化；暂不作为关键事件信号。双鞋失败例仍有清楚状态熵结构，所以“清楚”不等于“成功”。

另对各模态C单独筛选，结果在`examples/weighted-screen.json`：视觉的开笔记本等候选有局部结构；指令C振幅通常更小；动作C的靠前候选多数仍有较强chunk位置模板。这是探索性排序，尚未逐条录像验收，不当作方法有效性的证据。

筛选沿用原标准：少量突出峰谷、宽区或阶段转换；排除密集杂峰、周期性chunk模板和未知终止前缀。5动作中值只辅助筛选，展示的都是未平滑原曲线。7例是人工选取的机制展示，包含失败和位置效应对照，不代表总体收益；注意力不等于因果重要性。

## 使用与精度

`derived/*.npz`每行对应一个仍活跃的episode/query，曲线列数50；query、slot、requested/actual seed和native_retry可追溯。`submitted`与`executed_known`分开保存：只有两者同时为真才能称已知执行位置；成功终止chunk真实执行前缀未知。共有586950个已知执行动作位置。

全量轻量E/M复用原atlas的6位小数；不用于FP32微小差值复核。7例的`*_curves.npz`直接取原始FP32分数，并保留`allround_*`。每个例子的A/B/C、E、M、C和视频映射见`selection.json`，可直接核对数值与图。

视频只有query q前后帧q/q+1，不是逐动作录像；4 fps是预览速度。橙色区域是终止前缀未知。四模态加权图的纵轴分别缩放，以看清小信号，比较绝对大小应读纵轴/表格。

导出复用仓库内`tools/pi05_attn/export_derived.py`：

```sh
CUDA_VISIBLE_DEVICES= python tools/pi05_attn/export_derived.py \
  /data/chenyiteng/results/pi05-attn/20261010-video-v4 \
  /path/to/new-derived-directory
```

该入口只读取既有标量、manifest和验收回执，不加载原始Q/K、不占GPU。94批成功导出并实际加载分析，7例视频均完整解码、帧数=query数+1；无新增常驻管理程序。
