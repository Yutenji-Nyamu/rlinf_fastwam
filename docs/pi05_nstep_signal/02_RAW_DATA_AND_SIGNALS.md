# 保存什么，以及以后算什么

2026-10-31，设计稿。N是内部求解次数；H50是预测50个动作；K4是四份噪声。这三个轴分开。

## 先存原始数据

每个episode固定记录task、实际seed、slot、指令、原始权重版本/归一化、H/C、动作上限、成功或正常失败、异常类型和终止位置。每次query保存：

|字段|形状/含义|后续用途|
|---|---|---|
|原始观察|三相机图像、状态和指令；每query一份|可重算，不用从压缩视频还原输入|
|initial_noise|K×H×32，保留模型实际使用dtype|同噪声跨N比较和复现，18填充维仍属于模型输入|
|model_actions|N×K×H×14，模型归一化坐标|所有主信号的统一坐标系|
|env_actions|N×K×C×14，实际输出转换结果|确认实际提交动作、解释物理幅度|
|x_chain、z_endpoint、timesteps|各N的主噪声k0路径；N不同长度不同|离线DV；记录实际求值时刻与最终更新后状态的区别|
|执行信息|executed_N=10、noise_index=0、active mask、提交数、实际到达情况|只对真正执行部分作主要统计|
|视频及映射|25Hz完整主视角视频、初始/最终帧、逐物理步记录和路径投影|准确找画面、区分预测与执行|

仅主噪声k0留完整内部路径已足够本轮DV；其他三噪声存初始噪声和完整终点，不默认追加四倍内部路径。若将来需要四噪声DV，应显式另加预算。视频是25Hz覆盖执行，不是每个250Hz物理tick都编码一帧。

## 离线派生的曲线

1. **步数差异**：同观察、同噪声，分别比较N1/N10、N1/N5、N5/N10。主指标沿用两输出各坐标`std/(RMS+1e-8)`再平均14维；补充归一化动作RMSE。完整原动作都在，后续可分关节/夹爪，不锁死一种归一化。
2. **四噪声一致性**：每个N内部四份动作的相对分散度，以及不除RMS的绝对分散度；另算去掉执行样本k0、仅k1–3的版本，检查共享样本影响。称为分散度，不能直接称概率熵。
3. **DV**：`dv_score`对末5次求值的**干净终点估计z**求向量方差，不是速度v的方差。N10保留旧主口径；N5末5次覆盖整个求解时间，而N10末5次只覆盖后半段，必须单列这一窗口差异。
4. **N1的DV缺测**：只有一次求值，没有轨迹内变化可估计，标`NaN/valid=False`。不能用方差0声称一步特别确定。本次DV10取N10执行轨迹的当前观察，与该观察上的N1/N5旁路动作配对。

H50全部保存；主轨迹图只显示提交且实际到达的前缀，未执行部分虚线或单列。控制器TOPP路径压缩后的h是几何投影，并非精确逆映射，保留每臂投影误差；不能把所有末块提交位置都算已执行。

原始N10不是动作真值：这些差异表示求解预算引起的动作变化，不直接等于预测错误。四噪声分散度也不能仅凭局部同升就当因果关系。
