# π0.5 N1／N5／N10联合信号采集规划

2026-10-31。本轮仅回顾已跑通代码、确定数据协议并规划；未改推理、未占GPU、未启动采集。

目标：在机器人当前看到的同一场景里，比较同一个原始多任务π0.5分别算1、5、10次后给出的动作；同时保存四种噪声下的动作分散度及已有DV。先留足原始数据，再离线决定怎样画图。

这与10/29的Clean CP140／Uτ3 CP70双模型shadow不同，也与RLinf调瓶子单任务N5基座不同。本次规划继承10/17 U和10/19四噪声采集的Sidney多任务原始模型、归一化及RoboTwin配置。

## 当前建议

- 同一观察配四份初始噪声；每份噪声分别完整求解N1、N5、N10，得到3×4份H50动作。
- 保持H50、真实14维计分；执行长度沿用旧采集C50，任务/种子/动作上限从旧验收实配继承，不混入新的评估上限。
- 实际执行N10还是N1是唯一待用户选择的主要问题。前者沿用旧U轨迹，后者考察一步策略实际访问的场景。两者不能混作同一分布。
- 本轮提出沿用全任务50×32回合规模；正式预算和GPU需在实施时落实。单卡32环境有最近shadow依据，复杂任务回退16；不把四份噪声当成4个环境。
- 完整视频、初始／末帧、观察和动作对应关系复用旧链；一次记录后离线重算，不只保存几个最终分数。
