# 并行、有限验收与图册

2026-10-31，仅规划。用户已确认N10实际执行、N1/N5旁算；本轮不安排GPU，不修改当前队列。首份噪声k0的N10动作控制机器人，其余输出仅记录。

## 并行与时间

继承最近已成功32环境shadow：主推理B32，额外三噪声B96，三个N依次算，避免把多个分支的激活同时常驻。旧B96与两批B48短测为2.56/2.64秒、27.51/20.75GiB，是两模型N10旁路的历史测量，不能直接当本次总耗时。

正式前从32环境完整链试一批，测显存峰值、环境重置/执行、模型前向和记录耗时。B96若不足，先按两批B48处理额外样本；复杂任务环境端有问题才回退16。不从4环境逐级慢试。全任务参考规模50×32回合；优先完整覆盖，正常失败也保留，异常任务记缺测并跳过，不筛成功种子补满。

每次query逻辑计算量为4×(1+5+10)=64个单样本前向等价；旧四噪声＋U链约4×10+5=45，相比约1.42倍。若保留旧自动N5旁路再重算会重复，必须只算一次。这只描述动作专家计算，环境/录像/前缀开销不同，不能直接说总用时也乘1.42。首批实测再估全队列。

## 少量必要验收

- 主动作与主RNG对照一次：开关旁路后实际执行完全一致；N1/N5/N10初噪声逐份对应、都到t=0。
- 从保存的原数组重算三个预算差异、三路四噪声分散度和DV；值对应、有效mask正确，N1 DV缺测。
- 一批实际视频核对初始与成功/终止末帧、整段覆盖及动作对应；沿用已有视频validator，不再额外反复整包校验。
- 核物理GPU计算＋图形绑定；失败/超时沿用外层有界清场，只清自己的本批进程。正常未成功计失败，不能当异常跳掉。
- 源码、实配、任务seed、成绩、轻量验收推既有公开仓库；完整视频、原始观察和数组留本地/服务器。

## 图册按两层组织

**原始层**保持不变：保存的动作/初噪声/内部链/观察/录像/帧映射。**分析层**可重算：按完整episode汇总CSV/NPZ、生成矢量曲线和索引，不能只保存截图。

每任务挑1–2条清晰成功轨迹作为案例，同时保留全体成败统计。轨迹页展示完整视频、6–12张真实阶段帧、步数差异（三对）、四噪声分散度（三N）、DV10/DV5；曲线可勾选，避免所有线同时堆叠。横轴为实际动作位置，标动作块边界和未到达前缀。

总体页先用二维密度和分位数分箱看“分散度 vs N1/N10动作距离”，再分任务/逐轨迹/块内位置比较；绝对与相对指标同时列出。统计置信区间以episode为抽样单位，不把相邻动作当独立样本。不用相关性最好的定义替换预设主指标。

此前slot25说明局部曲线能同升，但全体相对指标关系弱；此次优先保存原始量和分组信息，不能承诺采完一定出现期望规律。
