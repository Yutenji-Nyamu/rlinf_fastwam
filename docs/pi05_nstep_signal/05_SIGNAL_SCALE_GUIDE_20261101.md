# 四种信号：绝对差异与相对差异

2026-11-01，核对实际采集代码。这里只解释现有统计，没有更改曲线定义或重新采集。

## 比较谁，比较什么

|信号|固定什么、比较什么|绝对版|相对版|
|---|---|---|---|
|步数差异|同一观察、同一主噪声，比较N1/N5/N10中两种输出|14维动作差的RMSE|每个坐标的两输出标准差除以该坐标RMS，再平均14维|
|四噪声分散度|同一观察、同一去噪步数，比较4份不同噪声的输出|各坐标的4样本总体标准差，再平均14维|各坐标标准差除以该坐标RMS，再平均14维|

每个动作位置都有一个分数；不把整条轨迹先压成一个数。动作处在模型归一化坐标，不是厘米或真实移动距离。当前N10主噪声动作实际执行，其余用于旁算比较。

“绝对”问：数字到底差多少？“相对”问：相对于该坐标输出本身的大小，分歧占多大？相对版不是简单把整组绝对RMSE除以一个整体动作幅度；它先逐坐标归一化，可能改变排序。

## 一个坐标的例子

|两种输出|绝对RMSE|相对分歧，忽略极小epsilon|
|---|---:|---:|
|-0.001与+0.001|0.002|1.000|
|0.999与1.001|0.002|约0.001|

两者相差同样多，第二组因为输出本身约为1，相对差异就很小。若四噪声分别重复上述两数各两次，两组绝对标准差都是0.001，相对分散度仍分别约1和0.001。

因此曲线峰值不完全相同并不矛盾。这里相对指标在0–1范围内，接近零的坐标不会无限爆炸，但很小的绝对差仍可能对应很高的相对分歧。π0.5使用绝对关节动作，归一化后的零点不等于“机器人没有运动”；相对分母也不是动作速度。

## 精确公式及复用位置

令某个动作位置的第d维为a_d、b_d，D=14，epsilon=1e-8：

```
步数差异绝对 = sqrt(mean_d((a_d-b_d)^2))
步数差异相对 = mean_d((abs(a_d-b_d)/2) /
                          (sqrt((a_d^2+b_d^2)/2)+epsilon))
四噪声绝对   = mean_d(std_k(x_kd, ddof=0))
四噪声相对   = mean_d(std_k(x_kd, ddof=0) /
                          (sqrt(mean_k(x_kd^2))+epsilon))
```

步数差异使用主噪声k0在两个步数下的输出；四噪声在每个固定步数下独立计算。两种绝对量聚合不同：一项是RMSE，一项是平均标准差，不宜直接比较它们的数值大小。

代码：[采集derive](../../tools/pi05_nstep_signal/observe.py)、[两输出和K噪声指标](../../tools/pi05_signals/signal_math.py)。现有相对指标沿用已验收的U/四噪声实现，绝对版由同一份原始动作离线计算。两者都是分歧信号；分歧大不自动等于动作错误，分歧小也不自动等于正确。
