# N1/N10差距与蒸馏早期曲线

2026-10-24。讨论与规划；未新开实验，未改变正式训练、预算或队列。

## 结论

当前原始模型是H50/C50：一次预测50动作，执行50动作再观察；N1/N10是生成这一块时计算1次/10次。N1同样跨完整噪声到动作区间，不是只做原来10步中的第一小步。两组当前正式训练是直接终点蒸馏、OneDP；不是CP。

同协议50任务各8回合，46任务有效，4任务仿真缺测。原始N1为191/368=51.90%，N10为193/368=52.45%，只差0.54个百分点。配对键用任务、slot、实际seed，保留重复seed所对应的不同slot。

|同一回合结果|数量|
|---|---:|
|两者成功|147|
|只有N1成功|44|
|只有N10成功|46|
|两者失败|131|

总分接近，不代表策略行为相同：90个结果不同，正负变化抵消。逐任务19个N10更高、13个N1更高、14个相同。当前每任务8次只能用于探索；不能用这8次挑出差距大的任务，再用同8次作为验证结论。

不能据此说两组都在首次评估前涨完。直接蒸馏后期仍出现较高点；OneDP早期与原始N1接近，后期下降。0–556之间没有成功率测量，也没有可补评的旧权重，无法排除中间短暂峰值。

直接蒸馏MSE中位数从前100步0.0054、101–556步0.0036，继续降到557–1113步0.0020、3340–5565步0.00085、5566–8904步0.00066。它确实更像老师输出，但动作平均误差变小不等于抓取、接触等关键位置一定正确。OneDP的辅助网络误差和带符号优化目标也不能直接当作成功率。

后续新训练可把少量评估放在0/100/200/400/800/1600更新，后段拉开；需与方法和数据预算共同确定。本轮没有补跑或早停。

## 把总动作上限改400是否有用

对现有C50轨迹按已记录动作数事后截断：N1在400动作内167/368=45.38%，N10为170/368=46.20%，差0.82个百分点；分别损失24/23个原本成功的回合。不是新400步实验，也不改变已有评估分数。

500动作的事后差距约2.99个百分点，600动作约1.36；这种阈值敏感性不支持事后挑一个上限当主协议。建议主结果保留各任务官方上限，统一截止时间/动作数曲线作为辅助效率分析。
