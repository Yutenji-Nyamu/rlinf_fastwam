# 两条曲线如何定义、怎样统计

## 分散度与动作距离

每个当前观察，学生4份动作`A_s[k,h,d]`；教师共用主噪声得到`A_t[h,d]`。H50保留，d只取真实14维，所有动作先放在同一老师归一化坐标中。

第一条沿用已有四噪声量：每坐标对4份输出求总体标准差，除以该坐标4份输出的RMS＋1e-8，再平均14维。保存名仍`noise4_u`。这是“多噪声动作分散度”，不是严格的概率熵；4个样本不能可靠估计14维联合熵。若后续要高斯对角熵，只作明确假设下的补充统计，不把旧指标改名。

第二条主量：`sqrt(mean_d((A_s[0,h,d]-A_t[h,d])**2))`，即同噪声、同观察、同预测位置的归一化RMSE。保存平方误差及14维差值，便于改用L2、关节/夹爪分项。不要把不同单位的原始关节和夹爪直接混加。若模型归一化不同，先都转换回环境坐标，再经同一个参照归一化；不能直接相减两套不同归一化的内部值。

教师动作不是唯一正确动作；距离大表示“与教师意见不同”，不自动等于执行错。N10教师也可能失败。不要在论文中直接写成ground-truth action error。

## 保存的最小原始材料

每query保留：task、请求/实际seed、batch、slot、query、当前状态与三相机观察/文字；主noise及额外3noise；学生4份和教师1份完整H50×14动作（模型/环境坐标）；两条逐动作信号、14维差值、active、before/after、offered/实际执行长度、success/终止；权重ID、N/H/C、归一化、任务上限与源码版本。

视频和映射沿用上次认可流程：完整头部视频及成功/终止末帧，frames JSON、控制JSONL、controller NPZ。模型动作到TOPP后的物理帧是左右臂各自投影，沿用已有误差字段，不声称严格一动作一帧。此处是专门绘图采集，应保留这些材料；普通训练评估仍关闭录像。

原始视频、输入观察、动作/噪声大数组保存在本地服务器/Home优先；Git推源码、配置、summary/曲线表、精选图预览。后续图册仍按过去成功版式组织。

## 全轨迹与总体统计

- 每任务选1–2条可读轨迹：上下两幅对齐同一真实动作横轴，分散度与距离各自纵轴；块边界、终止清楚，附3–5张真实帧与完整视频。主图用原折线；平滑仅作显示并保留原数据。
- 全局用所有有效成功/失败轨迹，不能只用精选图轨迹。未执行的预测尾段、成功后的冻结slot和仿真异常不进入已执行动作统计。
- 报告各任务Spearman、任务均衡汇总，以及分散度分位箱内距离中位数/四分位；另给散点密度图。按轨迹而非逐动作重采样计算区间，避免把同一轨迹的相邻动作当独立重复实验。
- 初步只看关联；再按任务、成功/失败、query/动作位置分层，排除“两个量都随时间下降”导致的假相关。
- 两量共用了学生z0，可能产生结构性相关。用已有4份学生输出再算“只用z1–3的分散度，与z0-教师距离”的敏感性版本，不额外推理；同时保留原4样本主结果。

这些统计检验的是“分散程度能否提示与教师分歧”，不是高熵接管一定有效的证明。接管实验仍负责检验实际纠正收益。

参考：[UA-OPD](https://openreview.net/forum?id=hHUZi8oHfo)的信号/外部质量分析；[ConformalDAgger](https://arxiv.org/abs/2410.08852)的学习者访问状态与专家动作偏差。相关工作用来确定问题和呈现，不把不同指标混作复现。
