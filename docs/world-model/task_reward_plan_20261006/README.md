# 单任务小奖励模型：收敛方案

2026-10-06；本轮为讨论与文档计划，未新增采集、训练、GPU借用或替换在线奖励。当前WMRL及RLT候补沿原owner运行。发布结果以本目录后续 `published.json` 为准。

## 当前决定

以 **WorldArena 的任务成功分类方案和现有奖励接口为主，先训练纯 ResNet18**。使用一个任务、一份权重，主相机图像输入，输出成功分数；该任务固定，第一版不需要T5理解不同指令。是否足够由留出数据决定，不预先升级视频模型或大VLM。

我们目前跑通的是 **自有RLinf/π0.5/GRPO＋OpenDW三视角预测＋WorldArena任务RM**。两个任务共用WorldArena的奖励组件与接线参考，动态预测和运行调度并非完整照搬其原装系统。这里“WorldArena为主干”特指本次奖励模型路线，保持已跑通的整个WMRL主循环。

不必追齐作者3000条数据及每项历史配置，目标是得到我们任务上可靠的0/1裁判。采用合理小规模配方并记录，称“沿用官方方法的本地训练”，不称原样复现公开checkpoint。

## 首批数据和顺序

首批目标 **100个独立回合，约50成功＋50真实失败**；按同reset种子成组，近似60/20/20分训练/验证/测试。它是我们提出的pilot预算，不是官方最低量，也不承诺已足以正式使用。训练帧的负正比另设约2:1，测试不用此比例重新筛图。

先盘点现有原生标注，避免重采。优先用摆瓶子已有成功与真实失败检查训练链；它已有Rynn原生32条（15成功/17失败），是否可复用取决于逐帧图像、标签和种子元数据完整性。按铃32条全成功，成功前的false帧不能充作失败回合。新WMRL目标任务另选原生基线有空间、完成状态可从主图看清的任务；尚未在本轮选定或切换任务。

顺序为：**复用/补齐小数据 → 自训单图RM → 固定留出评估 → 少量OpenDW画面抽查 → 另行进入接入smoke**。已有公开RM可在同份评估数据上作对照；以原生标签为参考，不要求新RM逐项模仿旧RM的判断。无需先完整重做两个旧任务。

## clean/rand判断

对齐clean/rand有帮助。当前继承配置的reset来自clean数据，原生相机为D435，随机背景/灯光等关闭；执行时仍核实际配置，不能只比较文件名。除此之外，统一主相机、RGB、裁剪、缩放及标签时刻。[已运行配置](../../../local_scripts/wmrl_bell_20261005/reference/formal.yaml)、[按铃执行记录](../robotwin_pipeline_20261003/click_bell_execution_20261005.md)

OpenDW输出与RoboTwin外观相近是一个有利起点；相同clean/rand不能保证接触位置、遮挡或物体形状完全保真。只保留约32段生成结果的小抽查，不因此先建大规模生成域数据集，见下文。
