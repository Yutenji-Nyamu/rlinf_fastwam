## 100回合怎么分

目标约50成功＋50真实失败，总100个独立回合。优先现有数据，按实际可用记录去重；“保留100条”不等于只需运行100次，尤其原策略接近满分时很难自然采到50条失败。比例允许近似，不为凑齐无限重采、不把提前截断或倒放伪装成真实失败。

| 集合 | 回合数目标 | 用途 |
|---|---:|---|
| 训练 | 60，约30成功/30失败 | 拟合ResNet |
| 验证 | 20，约10成功/10失败 | 选checkpoint与阈值 |
| 测试 | 20，约10成功/10失败 | 冻结模型与阈值后报告结果 |

相同reset种子/同条轨迹的重跑、裁剪、衍生窗口均放同一组，先分组再抽帧，必要时允许各组数量有小幅偏差。20条测试能发现明显问题，不能据此宣称低概率假成功已得到充分保证。若已经反复查看某些旧数据的成败/模型判断，将其用于训练或验证，另留新种子作最终测试。

可复用线索：摆瓶子Rynn CP70原生32条有15成功17失败；专家16条与这些数据并不自动等于48个独立且协议一致的可用训练回合，先核种子、相机、时刻和标签。按铃此前32回合全成功，RM小测中的32张false是成功前画面。小测“正负图数量”与“成功失败回合数量”分别记账。[Rynn标签结果](../robotwin_pipeline_20261003/rynn_binary_probe_20261005.md)、[按铃原生与RM结果](../robotwin_pipeline_20261003/click_bell_execution_20261005.md)

## 帧标签与采样

保存每个观察的原生 `success`，同时记录首次成功时刻、episode/seed、控制步与图像时刻。成功回合完成前仍标0；满足成功条件的对应观察标1。缺逐帧标签的旧专家文件不能直接按“回合成功”给所有帧赋1；需可靠时间对齐或补原生采集。当前成功与曾经成功的锁存字段分开保留，接触后画面不可判的样本标为问题样本。

首版每回合固定抽约8–16个分散时刻，并补首次成功前后、失败末段的少量帧；总量约千帧级，去除完全重复图，不把高度相邻帧当成大量独立证据。验证/测试预先固定抽样规则，另保留全部已记录时间点供整回合误终止检查；不能用候选RM分数挑漂亮测试图。

**两个比例独立：**回合来源约成功:失败=1:1；训练批次中未完成帧:完成帧先用2:1，参考WorldArena默认做法。成功回合自身也贡献负帧，所以不能从回合比例推算帧比例。验证/测试不再人为按2:1重采样；50:50回合测试也不是正式策略的自然成功分布，报告各类计数，勿当作真实部署成功率。

优先保留“接近目标但未完成”的负例，如靠近未接触、摆正程度不足、放置位置错误；这些比大量静止起点更有辨别价值。首版不新增视频模型，只借WMPO挑选时间上接近成功的负例思路。[WorldArena预处理](https://github.com/WorldArena2/WorldArena-2.0/blob/main/RL_env_benchmark/examples/reward/preprocess_reward_dataset.py)、[WMPO训练样本窗口](https://github.com/WM-PO/WMPO/blob/main/reward_model/videomae.py)

## 首版模型与参数

单任务ResNet18＋小二分类头，ImageNet视觉预训练，主图224×224，BCE，输出0–1分数；训练与上线共用一份RGB/归一化处理，不对原始画面做会改变成功含义的翻转或大裁剪。无T5、无任务文本编码；换任务单独训练和配置权重。

先参考WorldArena已公开的LR=1e-4、micro32/global64；实际训练入口复用其RLinf组件。小数据先短训、按验证损失早停，执行时记录具体最大步数、检查间隔及预训练版本；不把官方默认800 epoch当成必须跑满的预算。本轮未生成执行配置或宣布训练已跑通。[官方配置](https://github.com/WorldArena2/WorldArena-2.0/blob/main/RL_env_benchmark/examples/reward/config/reward_training.yaml)

成功分数阈值在验证集选定，再固定到测试与上线；不默认沿用旧文本RM的0.9，也不把sigmoid数值当作已校准的成功概率。首先看假成功和漏成功的计数，而不是只看总accuracy。

如果100条出现明显同类误判，下一批只针对该类补真实回合；若主要问题是时序不可见，改输入而不是无限堆相似静态图。默认不直接扩大到3000条，不预设50+50一定足够正式训练。
