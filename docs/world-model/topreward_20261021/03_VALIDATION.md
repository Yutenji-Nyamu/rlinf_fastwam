# 标定、短对照与放行

先用既有原生数据128条，固定选择与按actual seed分组的64/64校准和留出划分，成败均覆盖；同一seed或轨迹的帧不得跨两边。记录旧RM是否见过该seed，旧RM见过的数据只用于诊断，不称独立泛化评估。原生策略固定评估seed排除出标定。

沿过程逐块评分，保存native是否已成功、首次成功所在采样块、帧引用、raw token probability、旧RM结果、输入/实际处理帧数和耗时。没有精确物理成功时间的帧不得自行插值。最终episode标签不反向赋给所有前缀。

阈值只由校准集选择；0.46另外作为官方参考。首轮探索性放行条件：校准集无提前误报且成功轨迹召回至少50%；冻结后留出集提前误报率≤5%、成功轨迹召回至少50%，同时报告计数和区间。它是本次工程筛选标准，非官方通用标准；小样本不证明误报风险已消失。无可行阈值或分数严重混叠则停止奖励替换，不靠调留出集阈值放行。

服务器执行针对性测试：窗口顺序/reset/state恢复、B16拆分与活跃槽缩减、原生success时序、阈值边界、处理器8/16帧及单token定义。GPU验证只用SZ2物理4/5。先1条视频验证，再完整离线评分，随后B16总延迟和与WM共同驻留的显存实测；逐视频串行不能当成一次B16前向。

通过后使用同一固定WM、原始π0.5、相同reset和训练预算做旧RM/Qwen短对照；先完整一轮采样、更新、保存、原生评估，确认有组内奖励差、非零有效样本和更新。新seed的原生128回合用于策略效果判断。WM生成视频分开检查，不套用同seed原生结局作为真值。

正式目标沿用200轮，10轮保存/固定评估；短对照默认每臂10轮，属于正式前比较，配置和资源回执先列明。若VLM持续全0/全1、无组内差、提前误报、原生能力下降或预算无法满足，则停在完整保存点、记录结论；不把服务ready等同于训练成功。
