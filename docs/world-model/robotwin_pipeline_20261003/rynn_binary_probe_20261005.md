## 如何理解结果

成功1应表示原生任务已成功，不等于画面“有所进展”。数值过程是否单调不是本次通过条件；重点是成功漏判与失败误判。

成功片段终点是首次C32边界观测到success，物理成功可能发生在该32动作块内部。32条只是小规模原生诊断，即使可分也不证明OpenDW生成画面上同样可靠；也没有覆盖全部在线中途失败前缀。若本批没有同时出现成功和失败，不能报告成败可分。
