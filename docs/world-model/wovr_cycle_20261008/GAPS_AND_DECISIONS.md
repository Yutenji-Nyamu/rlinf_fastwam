# 本轮收敛：保留哪些、补哪些、哪些不做

2026-10-08；只讨论和修订文档。按用户最新取舍，以OpenDW现模型为准。旧全貌讨论见[归档](archive/20261008_before_chunk_only_cycle/GAPS_AND_DECISIONS.md)。

| 项目 | 本轮结论 | 是否仍阻挡实现 |
|---|---|---|
| chunk级学习 | 保留成功所在C32及现有loss；之后终止，不加块内细分/新长度归约 | 否，继承已有路径 |
| 多时刻历史/回合参考图 | 保留OpenDW单时刻三视角拼图，不改结构 | 否，移出本轮范围 |
| KIR | 不加中间起点池，沿当前reset | 否，移出本轮范围 |
| 更新间隔 | 接受用户按曲线选的每10轮 | 已明确 |
| 原生采集 | 同步三图、逐条命令/command state、原生标签，独立采集seed | 清晰工程，待实施 |
| 默认32D与当前14D差异 | 数据/model配置按当前14D absolute、原mean/std、原resize处理 | 清晰工程，待实施 |
| RM更新 | 建议同批真实数据、同一离线阶段单独训练；不合并模型/梯度 | 路线清楚，不需联合训练开发 |
| GPU范围 | 4/5两卡分阶段复用；RL N64/R8、WM推理B16不变 | 已明确；WM训练batch另测 |
| WM训练量 | OpenDW通用默认5epoch作为候选，按实际窗口与有效batch换算步数 | 首次微调需测耗时和效果，不能保证默认够好 |
| 守护/校验 | 原有owner和故障归还；不新增常驻看护、反复全量校验或任意缓存限制 | 继承简洁实现 |

这次保留的是“策略RL—原生采集—模型更新—继续策略”的闭环，借鉴PACE，准确标明不含完整WoVR的历史/KIR/特定loss改造即可，无需为了名称补不需要的复杂度。

采集量建议：初始150训练＋32留出，后续每10轮100新训练，可混50旧训练；200轮到190轮前共19次补采，2050训练＋32留出。这个预算比论文单任务平均250条更大，属于我们的多次轮换方案，尚未启动。数据比例和epoch都是本轮建议，不能写成官方已验证的π0.5/OpenDW配方。

原生数据能分别纠正WM和RM；RM仍可能在生成图上误判，最终效果继续看原生策略评估，不用WM奖励上升替代真实成功率。
