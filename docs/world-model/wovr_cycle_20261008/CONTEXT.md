## 本轮数值建议，尚未启动

原始策略先采150条训练轨迹，另采32条固定留出；以后每10轮新增100条训练轨迹。150/100参考WoVR的单任务量级，其中后100为论文suite预算按10任务平均。每次100新轨迹可混50条既有训练轨迹，避免只学最新行为；这50条不需要重采，也不要求成功失败各一半。

若策略总预算仍200轮，在第10至190轮更新，共19次补采：150+19×100=2050条训练轨迹；加32条固定留出共2082条。原有每10轮32条原生策略评估另计，不进入WM/RM训练。这是比论文一次更新更大的我方循环预算，数值仍是本轮建议，不是已获新实验执行授权或论文原配方。

WM每阶段可先以官方通用默认5个epoch作为训练预算候选；具体optimizer步数取决于有效C32片段数和训练有效batch，需首次短训测吞吐/效果，不宣称5遍保证收敛。RM可与WM使用同批原生数据，在同一个离线阶段分别训练，保持独立模型/目标，不做联合反向。
