## 横轴到底是什么

保持以前DV的逐动作粒度：每次决策输出H=50个14维动作，保留每个h，不把整段平均为一个点。拼接后横轴为提交给控制器的动作槽位，q为决策序号、h为chunk内位置，均从0开始。

TOPP会将这些动作槽位转换为底层控制轨迹，因此一个槽位不等于一个物理仿真步。成功终止的最后一个chunk只知道提交了哪些动作，不能恢复精确的物理执行前缀。该段曲线保留并涂橙色，**不参与候选排序、标记片段或相关性诊断**。这避免把未执行的未来预测误当成重要接触。

视频只有每个chunk前后的记录：q对应前帧，q+1对应后帧。可以看“这段由接近变为抓取/移动”，不能定位h处的精确接触瞬间。没有插帧，也没有制造峰值时刻画面。

## 八个固定分数

主求解10轮，旁路5轮；动作维度14。所有分数最终保留h。以下是本研究适配，不能称为原论文在机器人上的完整复现。

| 信号 | 使用的记录 | 固定计算及含义 |
|---|---|---|
| DV | 每轮clean estimate `z_endpoint` | 末5轮相对均值的14维向量距离平方，再沿轮次平均；等于14坐标总体方差之和。看各轮预计终稿的一致性。 |
| Fresco-tail5 | 每轮网络输入 `x_chain` | 同样的向量方差，但使用末5个带噪草稿。x共11份，只用前10个求值输入中的末5份，不包含额外最终落点。 |
| GEO-full | 10轮直接输出的v | 相邻v的14维L2差累计，除以10轮v长度的平均值加1e-8；是路径变化率式分数，不是v方差。 |
| GeoAAC-growth | v和生成时间 | 逐动作前缀计算带阶段权重的几何分数，再取加入下一个动作后的正相对增长。h=0无前一个非空前缀，保留NaN/无效。不是单动作独立不确定性。 |
| SHIFT | 第一轮和最后一轮、18层hidden各自的均值 | `log1p(L2(last_mean-first_mean))`；看首末表示调整。已保存两份均值，未保存全部18层的完整向量。 |
| Tell-Tale Norm | 10轮×18层的每动作L2范数 | 末5轮、最深3层的15个范数取均值。看表示幅度，不能直接叫重要性。 |
| SR-window5 | 最后一轮末层pre-finalnorm hidden | 以h为中心取固定5动作邻域，边缘窗口向内平移；矩阵Frobenius范数平方/最大奇异值平方。未中心化、未逐行归一化，衡量邻域方向丰富度。 |
| U-GROW 10vs5 | 同观察、同完整32维初噪声的10轮和5轮最终动作 | 每坐标两份输出的总体标准差，除以其RMS加1e-8，再平均14维。完整求解两次；不是10轮中的第5份草稿。 |

GeoAAC的精确实现：对于求值轮次j，阶段中点u=(j+0.5)/10，权重w=u(1-u)^2并归一化至平均1。将前缀1…h的v拼接为V，a为相邻V之差除以生成时间间隔加epsilon。前缀分数为 `10 * sum_j(w_j * ||a_j||) / (sum_j ||V_j|| + epsilon)`；随后取 `max((P_h-P_{h-1})/(abs(P_{h-1})+epsilon), 0)`。前缀分子、分母同时改变，所以分数可以下降，不是把单动作不确定性相加。

SR离线采用5×5 Gram矩阵的特征值，与原SVD定义等价；全1077次批量决策最大差1.33e-15。其余七条与记录分数数值完全一致，有效掩码全部一致。

## 原始量是否足够

每次批量决策B=16，主要字段包括：

- x `[16,11,50,14]`、v/z `[16,10,50,14]`、10个生成时间。
- 完整初噪声 `[16,50,32]`，主/旁路最终模型动作 `[16,50,14]`，旁路步数与时间终点。
- SHIFT首末层均值 `[16,50,1024]`；Norm网格 `[16,10,18,50]`。
- 每轮末层hidden `[16,10,50,1024]` FP16；SR另存末轮hidden FP32。
- 环境动作、active/submitted/executed掩码、动作槽位起止、成功标记。
- 主相机、双腕相机、状态及视频索引；18层hook计数。

足以重算本轮八条定义。不能声称保存了任意层的完整hidden，也不能从现有视频恢复逐物理步画面。

## 怎么把结构与噪音区分

先批量筛，再看图；允许少量峰，也允许持续高/低区和阶段转换。

1. 优先正式验收数据，再优先成功轨迹；补充和失败例明确标记。
2. 综合相对变化幅度、局部连贯性、峰的集中程度和持续阶段差异。5动作中值滤波仅用于排序，**主图始终画未经平滑的原始值**。A/B/C为启发式形态等级，不是p值。
3. 用同任务的其他轨迹构造chunk位置模板；对每条轨迹都排除自身。重复出现于同一个h的形状会降低排序。详细图第二行是去位置模板后的诊断，第一行原始曲线不改。
4. 看过46张任务总图的全部8行，共368条曲线及各自chunk前后帧。逐条备注分为candidate、phase_only、confounded、weak、no_data；candidate只是可解释候选，不是排除噪音的统计证明。
5. 检查与初噪声幅度、初噪声到最终动作距离、动作幅度、平均v幅度、相邻动作变化的相关性。先在每条正式轨迹的非终止部分算Spearman，再汇总中位数；不足15个有效动作或常数序列不计。

本次形态阈值：5动作中值后，用10动作滑动窗口比较高低区；变化幅度用q95-q05相对中位数衡量；连贯性由中值残差和相邻差分共同计算。A的条件为连贯性≥0.75、相对跨度≥0.03、区域对比≥0.7；B为≥0.5、≥0.008、≥0.4。另保留1–2主峰筛选和GeoAAC稀疏增长例外。完整实现见离线脚本；这些人为阈值只为浏览排序，不用于性能结论。

位置模板本身是诊断启发式，不能证明位置变化是伪信号，也未覆盖动作任务阶段与位置之间的所有关联。`position_bias.png`汇总的是所有已提交槽位，包含橙色终止段，和排除终止段的相关统计范围不同。

## 本轮能说到哪里

- Fresco与初噪声到最终动作距离的轨迹内相关中位数0.998；SHIFT为0.818。当前适配明显受生成路径长度影响。
- 若草稿沿近似直线从噪声走到动作，跨时间方差就会随这段距离的平方增大；这提供一种可检查的解释，不等于条件随机不确定性。
- DV/GEO/U-GROW的候选有较清楚的局部或阶段变化。Norm部分宽高区也可展示。SR/GeoAAC常见chunk位置模式，应按邻域/前缀含义解释。
- 每个任务每个信号选出的最好例子，属于展示性筛选；不能据此声称训练提升、失败预测能力、跨种子稳定性或因果重要性。未重新采样检验同一观测下的重复性。
