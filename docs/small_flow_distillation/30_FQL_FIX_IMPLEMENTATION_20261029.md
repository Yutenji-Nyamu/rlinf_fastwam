# FQL-fix：降低Q推动，并在真实执行中核对评分

2026-10-29用户授权实现及双卡smoke，测试后停止。本版沿用已验收的原生RLinf adjust_bottle单任务版本。源码独立部署，不改正在运行的4–7卡队列。

## 两项改动

- `alpha:10→30`，仍为`alpha×H50真实14维端点MSE−Q`。Q网络、更新顺序、学习率、折扣、目标EMA及数据不变；未加入Q预热、取小Q或额外保守正则。
- `q_diagnostics:true`：完整保存点额外导出小Q；评估复用策略已经算出的视觉语言前缀和归一化动作，每块记录双Q。按同一`gamma=0.99`倒算成功一次奖励的真实回报，输出MAE、偏差、越界比例、双Q分歧和分箱校准。不重算视觉语言前缀，不开录像或逐物理步记录。

训练Q和评估Q共用同一个`pooled_features`函数。Q导出必须与学生的step、base、C匹配，利用已加载的学生元信息核对，不额外重载大权重。Q诊断开启前后以同种子核对动作和CPU/CUDA随机状态相同。

## 本轮实测结果
