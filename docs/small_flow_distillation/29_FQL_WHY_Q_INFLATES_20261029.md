# Q为什么能把最多1分的任务估到4分

2026-10-29，教学补充；未改FQL训练，没有重开修复实验。

## 先分开两种“答案”

**环境给的答案**：这一局到底成功没有。我们成功只奖励一次1，失败0，所以真正的未来折扣回报最多1。

**训练Q用的答案**：不是每次都拿最后的真实成败来监督。数据里取出一条“观察 → 老师动作 → 下一观察”，当前尚未成功时，Q的学习答案是“下一观察下，学生准备做的动作有几分”，再乘0.99。这个“有几分”仍是另一个缓慢更新的Q副本预测的，不是新的真实执行结果。

为什么用学生下一动作：想评估的是“以后交给现在的学生继续做，会怎样”。旧轨迹只记录老师当时怎样做，并没有试过学生提出的所有动作。因此这里必须依赖Q的泛化，而我们的数据对这些动作覆盖不足。

## 一个具体例子

1. 瓶子前的状态，老师曾握住瓶身；数据里有这种动作及后果。
2. 学生提出一个不同的手臂动作，数据里没有实际试过。Q可能错把它评成2分。
3. 学生的优化目标里有“让Q更高”，于是它会更偏向这种被误评的动作，即使该动作真实不可靠。
4. 学习上一状态的Q时，“下一步2分”又变成约1.98分的训练答案。于是连数据中原有动作的评分也被这个错误答案带高。
5. 学生还会找到被错评得更高的动作，误差继续进入下一批训练目标。

**单独乘0.99不会把分数越乘越大。** 推高它的是学生持续寻找评分漏洞，加上网络在没见过的动作上的误判；自举更新再把这些错误传播回来。目标Q是缓慢更新副本，能缓和变化，但不是独立的正确答案。

所以，Q损失从大变小，只说明“当前Q越来越像它自己的训练答案”；若答案本身偏高，loss很小也可以一起错。实际数据支持这种机制，但还没有对照证明它解释全部退化：110步成功率已经很差，当时Q均值尚未超过1。

## 属于哪一层问题

| 层面 | 本轮结论 |
|---|---|
| 奖励/终止编码错误 | 之前检查128条轨迹、405条转移，未发现重复奖励、终止仍接未来Q或错位的下一状态；不能据Q=4直接断定某行代码写反 |
| 离线RL机制 | 固定旧数据＋对未见动作打分＋学生追高分＋预测作训练答案，是已知的高估风险；原FQL也有这条路径 |
| 我们的适配与参数 | 单任务只有405个动作块转移、13条失败轨迹，Q要评50×14维动作；已有能力的学生从一开始就受Q引导，alpha10没有按此任务校准，容易暴露上述风险 |

原Q最后一层是无界实数回归，程序没有自动把数限制在[0,1]。输出4说明价值估计失真，不代表环境发了4分；强行截到1也不能保证它把好动作排在坏动作前。

## 修法与它分别解决什么

1. **先减弱错误Q对学生的推动**：现有`alpha*MSE-Q`把alpha10改30，让学生更靠近老师。固定梯度下Q相对约束降到原来的1/3；这是防止走偏，不是校正Q答案。
2. **在既定评估中测Q是否说真话**：每块记录Q，结束后倒算实际回报，按任务/时段和预测分箱比较。128回合最多512条小记录，不需录像，也不新跑一轮环境。既看平均偏差，也看高分动作是否真的更容易成功。
3. **如果仍明显高估，再单独改Q训练**：Q预热减少随机启动影响；双Q目标取较小值减轻乐观偏差；更保守的离线Q正则针对数据外动作，但已是新的算法改动。分开对照，避免一次改变多项后无法判断原因。

当前收敛仍是`alpha30＋Q实际回报诊断`。Q单独预热是候选，没有把任意预热步数写成官方设置。要把“失败因为什么”变成验证结论，还需要这一版诊断与对照。
