# CP new：适配候选，待讨论决定

2026-10-28。本轮只构思、审计、规划；未改正在运行或等待的旧CP，未启动新版。

## 两个独立切口，尚未确定组合

同日扩展调查见[17](17_PADDING_OBJECTIVES_SURVEY_20261028.md)。原建议“两项都改14维”现明确为候选A；候选B是一致性14维、专家FM保留32维，以保留OpenPI式监督。不能把全维评分直接定性为bug。dropout的具体路线和位置见[18](18_CP_DROPOUT_WALKTHROUGH_20261028.md)。用户希望先理解再决定，以下不是启动配置。

|位置|改法|依据与边界|
|---|---|---|
|一致性及FM损失|候选A两项14；候选B一致性14/FM32，仍训练H50|A集中真实动作；B保留原生零填充FM约束；内部接口与加噪仍32维|
|CP训练前向|候选在学生和EMA动作专家隐藏特征加入p=0.2 dropout，覆盖最后s→0两次前向|原CP隐藏特征扰动有依据；只扰动收尾可作为更窄的机制对照；教师/冻结VLM/评估关闭|

mask应先选14维，再按有效元素平均，不能补零后仍除以32。官方距离delta按参与评分的维度计算，因此H50×14对应约0.01429，旧H50×32为0.0216；把这一随mask变化的尺度记入配置，不冒充数值不变。

π0.5没有原版U-Net残差块。首个具体工程候选是在**动作专家各GemmaMLP输出、进入残差合并之前**接训练期dropout，通过本项目包装注册局部模块/钩子，不修改共享site-packages、不影响VLM。安装版联合前向直接调用MLP，跳过DecoderLayer的完整forward，所以不能只给DecoderLayer挂钩后以为已生效。这是Transformer适配位置，不能称与U-Net两个位置逐层等价；实际短测需验证调用和输出扰动。

旧模型保持eval式前缀缓存；dropout只由CP训练上下文启用。EMA参数继续冻结，预测分支对输入继续可导；目标整条no_grad但仍可随机前向。各次调用使用正常推进的RNG，不把两路mask人为强制相同。梯度重算须保留对应前向的随机状态，完整续训继续保存两卡RNG。推理时关闭新增模块，N1/H50/C50均不变。

## 其余先沿用已跑通设置

原生RLinf adjust_bottle老师N5，50示范/4738窗口；老师与学生从同一个原始权重开始，不接旧CP末代。冻结视觉语言部分；两卡、每卡80、全局160，FP32专家主权重/BF16计算；lr2.5e-5、原优化器/clip1、80时间格、Euler局部老师步、原EMA计划。数据FM仍采用π0.5的Beta时间采样及速度MSE。方法改动不借机改任务、动作上限、学习率或数据。

正式预算建议与旧CP完整对照采用**200预算轮=6000更新**，沿旧前密后疏的12个100轮内评估点，再加120/140/160/180/200，共17点，每点128回合。因为旧CP前100轮已完成一次余弦衰减、后来才延期，学习率比较应明确：若追求方法对照，CP new同样保留“首100轮旧调度＋后100轮扩展调度”，不能悄悄从零采用不同的200轮调度。该预算尚未下发；若实施，先在100轮结果处再判断继续价值也可。

## 少量必要检查与诊断

- CPU：填充维单独扰动不改变被mask的损失；14维改变能影响损失；p=0时与原前向一致；老师/前缀/评估确定性；EMA预测分支梯度能到学生，目标分支不反传。
- 短GPU：沿已测每卡80起步，少量更新、完整恢复、实际导出N1评估；核对真实dropout调用、显存/耗时，不能只检查配置字段。无需从很小batch爬坡。
- 每个已有日志点记录真实/填充误差、中间差异与终点差异，不加额外模型前向。分项梯度只在少量诊断步计算同一动作输出层上的范数与方向，用来判断一致性是否有信号；注明不是全网络梯度占比。若额外反传成本明显，缩减诊断频率。
- 成功率对比原始N1/N5及旧CP，同种子同预算。若同时改mask和dropout有效，只能先归因于这个组合；再用少量mask-only对照区分来源，不预先堆矩阵。

上述mask/dropout不会让模型变小；性能主要看目标和信号质量，不承诺加速或超过老师。当前不建议同时更换距离、自动配loss权重、增加新监督或改推理噪声，这些需要分项证据再决定。
