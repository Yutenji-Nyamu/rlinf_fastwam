# 单任务蒸馏下一步：已有大模型桥梁与小模型平台

2026-10-27初版规划保留。用户随后选定RLinf π0.5并授权最小原始评估，执行以[08号](08_SINGLE_TEACHER_EVALUATION_20261027.md)为准：默认N5对N1，差距小才追加C10；本轮不做N10大矩阵，也未启动五方法训练。

## 推荐顺序

1. **最快复用：已有RLinf π0.5单任务adjust_bottle。** 老师权重和环境流程都在，动作专家与现有直接/CP/DMD/MFD接口接近，主要处理数据变换与评分协议。先确定原始N1与多步差距。
2. **真正降低每步模型计算：再选小型FM。** 跨RoboTwin/Dojo接入优先继续核SmolVLA；更纯的小网络优先参考PointFlowMatch的RGB FM＋U-Net，结合两基准现成DP接口。这里仍需建立合格教师，不是拷贝代码即有高成功率。
3. **ManiFlow/FlowPolicy保留作一致性方法与架构参照。** 若直接拿它们当老师，先看是否仍有值得蒸馏的N多步/N1差距；不能为制造差距随意破坏原模型。

单任务π0.5仍是大模型，每次前向不会因只训练一个任务而变小。省下的是数据范围与50任务评估量。它适合快速复用现有五方法验证方向，不能代替“小型策略可快速大量试验”的长期平台。

## 第一阶段：只读确认后，未来最小对照

已完成：查明两个官方SFT模型的文件、固定版本、动作变换、旧运行来源。未完成：当前评估器下的新N1/N多步成绩。

未来先用RLinf π0.5做同一批种子的N1/N10各128回合；增加原生N5作为一次协议锚点有明确依据。默认先复用该老师原来的H50/C50、clean、200动作上限，不与Sidney的400动作分母混合。若研究原生RoboTwin400动作，上限作为另一套明确协议整体更换并重测老师；这里不擅自改现有实验。

若N1/N10差距已经明显且多步成功率合适，进入五方法；若两者都很高，再以统一C10复测，其他设置不变。C改变的是重观察频率，不改变H和训练目标。不能只压低时间上限制造人工失败。

原始π0默认N4，若选择它则另测自己的N4/N1/N10；不把π0的N4和π0.5的N5混用。模型/老师优先定一套，避免第一轮同时比较两个大模型与五方法。

## 参数依据与预算

|部分|计划继承及依据|
|---|---|
|相机、动作维、normalizer、状态输入|选定老师的官方配置＋旧成功部署；内部32维，真实14维计分|
|H/C/N|H50；先复现原模型C50和N5，再做固定协议N10/N1；需要C10时所有老师/学生共同调整|
|训练范围|冻结视觉语言前缀，只训动作模块；这是现有蒸馏设置，不是声称原SFT也冻结了VLM|
|直接蒸馏|复用当前2.5e-5最高LR与衰减形式，重算单任务时间表；固定教师、同噪声端点|
|DMD new|用户已定学生1e-5、辅助2e-4、辅助5:1、学生H50×14；原OneDP论文默认是1e-6/2e-5，不混称官方值|
|MFD|沿验收版本两路Euler积分、最大步长.02、辅助速度回归；继承DMD-new学习率是我们的适配|
|CP/FQL|方法项沿已验收实现；CP用专家动作，FQL另用真实转移，不把信息权限说成和直接完全相同|
|训练batch|π0.5既有每卡192是容量参照，不自动变成单卡已验收值；单卡/双卡总batch改变时按总样本预算重算更新数|
|供数|现有线程解码＋有界预取，保留端到端计时；不用新一轮从极小线程数盲目爬升|
|评分量|首尾128，训练过程约20个点、每点64，前密后疏；并发候选32/64从已跑通附近比较端到端吞吐|
|停止/存储|完整恢复成功、loss/梯度有限、输出协议对齐后才长训；最近2点＋最好/末代完整续训，小日志持续归档|

总训练步数应按该任务有效窗口W与样本预算计算，不套用多任务55,650步，也不因数据小自动照抄50预算轮。已有单任务CP曲线与OneDP设置可作为预算参照，最终在启动表中同时列学生更新数、样本数、辅助更新数和预计墙钟时间。当前未给出未经实测的总时长。

## 最少且有意义的验收

1. 固定观察/噪声，旧原生评估入口与新adapter的多步动作一致；delta→absolute往返正确，夹爪不被错误差分。
2. 一次短训练记录真实可训练参数、前C/全H误差、真实/填充维、梯度与资源；短续训＋实际导出N1验证。
3. 若用π0，额外检查state/time模块确实更新且能恢复；CP条件投影不能漏存。
4. 正式评分关闭视频/信号；程序异常单列，机器人未成功计失败。复用原故障跳过、精确清场、候补机制，不自行扩展测试。

对小型FM，沿同一接口迁移五方法；PointFlowMatch原配置包含末端位姿xyz/旋转/夹爪专用权重，迁入RoboTwin14维关节后必须换成相应动作语义，不能照搬10/10/1。已有RGB版本免去强制点云改造，但不代表无需训练教师或验证模型接口。

当前决策点是选“现有单任务π0.5先快速复用”还是“先投入小型FM教师”；本轮为两条路径整理依据，不擅自启动。
