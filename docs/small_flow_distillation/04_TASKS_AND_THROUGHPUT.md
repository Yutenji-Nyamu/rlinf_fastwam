## 顺序

1. **选一个基座、一个任务**。取得/训练合格的多步教师，记录原生模型、归一化和相机接口。
2. **建立压缩空间**。配对种子评教师原生多步与未蒸馏N1，各先32或64回合。SmolVLA先N10；FMP先比较N10/N20是否已稳定，再定教师步数。最终基线各128回合；不以一次32回合的随机差决定结论。
3. 若差距小，固定H，仅改C：SmolVLA可C50→C10并视情况C20；FMP按H8/O3从C6→C3→C1。所有方法用同一个选定C，不为某个方法单独挑有利条件；保留所有已试设置的结果。
4. **五方法**沿用同老师、初始化、数据split与成功率协议。先直接端点验证输出与导出，再接CP/DMD/MFD；FQL需真实转移后再训。单任务都通后扩大为五个独立任务，不一次启动25组排查。
5. 继续讨论后才进入实施；本轮没有启动smoke。

## 训练并行：用少量测量定位，不以填满显存为目的

训练batch是在一次参数更新里合看多少窗口；仿真环境数量是另一件事。batch加大可提高矩阵计算吞吐，但达到饱和后不再提速。固定更新数而扩大batch，还会增加总训练样本预算；固定样本数则更新次数变少，学习率和预热时间表应重新计算。

- **SmolVLA**：XPolicyLab已有B512参考。先核实际模型/优化器/图像与KV内存估算；预计可放时直接试B512，并用B256作吞吐对照，必要时只补一个预测的邻近容量点。B512不是80GB卡已验收值。
- **FMP-U-Net**：官方DP B128作为参照；冻结编码器的蒸馏可直接估算B512候选，不机械从B1/4/8增长。教师SFT训练编码器，内存需求另算。
- 两点稳态峰值可近似拟合`M(B)=M0+mB`；目标保留约10%–20%显存余量。内核workspace和观测shape变化可能非线性，预测点只需一次实测确认。
- 分别量样本/秒、完整更新秒、CPU供数等待、H2D、教师前向、辅助5次、学生反传、峰值allocated/reserved、RSS。不是只看nvidia-smi显存。
- 正式batch选吞吐已接近平台且梯度有限、恢复成功的一档。三网络的DMD/MFD与直接方法分别量；MFD积分通常增加计算时间，不按多34个前向推断需要34倍显存。
- 使用基座支持的BF16；时间/平均速度累积和损失关键归约FP32。学习率不随batch盲目线性放大。

可优先提速：冻结视觉模块时只编码一次，教师/学生/辅助合法复用；数据解码与GPU计算重叠；确定性且冻结的特征可按帧缓存。若视觉训练/随机增强/state projector变化，则相应缓存失效，不能为了速度悄悄改变训练信息。

## 评估并行与频率

- 一张卡一个常驻策略服务，模拟器多进程，动作网络真正batch；不为每个环境各加载一份老师/学生。
- RoboTwin候选总并行32对64，固定总128回合比较端到端回合/小时，避免不同回合预算误判速度；复用已有成功调度。Dojo若后续实施，从历史24/25环境量级向预测较优并发测，先看CPU/RSS和渲染瓶颈，不能照搬RoboTwin64。
- XPolicyLab的DP及SmolVLA代码已有batch推理参考。DP每环境O3历史独立保存，并按真实动作时序更新；不能只在每次chunk决策时采一帧却仍声称O3物理步历史。
- 普通评分关闭视频、U/DV/多噪声、逐动作日志及映射。保留回合seed、成功、执行长度、错误类型、重置/推理/环境/总耗时。FQL采集另用数据契约，不能把所需转移也关掉。
- **约20个非零评估点＋起点**：前期可用预算比例0.25%、0.5%、1%、2%、4%、7%、10%，之后分配至100%；映射到整数更新后去重。每点建议64回合，最终候选128回合、用另留种子复验。64并行则一批，32并行则两批。这是单任务精度/吞吐折中，不把多任务每任务8回合直接沿用。
- 正常没完成计失败；程序/仿真异常单列缺测。卡死/同类重复错误按现有wrapper跳过、清理本批进程、继续下一项，不无休止重试。

## 预算与可比性

总步数目前不锁死：基座和实测吞吐未定，不能保证几小时完成。SmolVLA参考100k更新与DP参考600epochs不是同一预算。正式前按单任务实际窗口数W与batch B给出`总学生样本数 / B`、学习率时间表和20个评估点；固定样本预算、实际参数更新数、GPU小时三个横轴都记录。

同一学生更新的额外工作：直接有教师N步前向；CP有桥接/EMA和专家FM；DMD new有辅助5次；MFD另有两路变长积分；FQL有Q更新且先花时间采集。它们不可能仅靠相同“更新数”就表示相同计算量。

预计总时长公式：`教师训练 + 方法更新数×稳态每次更新时间 + 全部评分回合/实测回合吞吐 + 保存/加载 + FQL采集`。前缀常驻和不退出训练的短评可减少重载，但只在显存允许、恢复状态清楚时采用，不先为这一点重写调度。
