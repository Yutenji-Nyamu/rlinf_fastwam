# Dojo起点落差排查与GRPO保存点 · 2026-11-04 09:53 CST

## 结论先行

历史52%=原生Dojo JAX π0.5 seed1/59999、N10/H50/C50、700动作、50局。当前0/32不是同协议原策略复验，而是DSRL的重复噪声起点。当前12轮评估1/32；截至22轮，已记录训练批次均无成功（恢复回退导致日志有重复轮号，不把重复行累加成独立预算）。

首要嫌疑是重复噪声对本模型的影响，不能把落差直接解释为“训练没收敛”。尚未做同布局闭环A/B，不能宣布它是全部原因。当前仅诊断，训练、原生仿真与队列均未修改；两次只读模型输出probe总约98秒，均仅6卡，已退出。4/5 GRPO、6 DSRL、7 RLT继续。

## 本轮小对照

从当前部署保存的8份初始观察读取，不启动/reset模拟器，不更改训练模型。冻结原基座；独立与重复噪声共用首行32维；另外两项对照排除普通随机变化和精度差异。

| 比较 | 12个臂关节目标RMSE |
|---|---:|
| 两套独立噪声，首行相同 | 0.103276 |
| 独立噪声改成重复噪声，dtype一致 | 1.160777 |
| 独立噪声仅float32改bfloat16 | 0.000724 |
| 实际DSRL入口与显式重复噪声 | 0 |

重复噪声差异约为独立随机对照的11.2倍。它改变了动作分布，而非只造成细小数值误差；这些是静态输出差异，不是成功率或动作真值误差。原动作小数组和可复现probe保留。

此前model_contract直接调用sample_actions并注入独立50×32噪声，验证了转换/变换，却绕过了实际DSRL噪声路径。先接正式、未补齐同协议原策略SR，是验收缺口。重复噪声本身有论文依据，不能说是无依据的写错一行。

## 最小下一步，尚未启动

先保持同任务、同权重、N10/C50/700和现有仿真，补一组32局独立噪声原策略评估；布局及物理替换逐局留记录，再与同布局重复噪声对照。若原策略回到明显成功而重复噪声仍低，才改噪声参数化；若两者都低，转查闭环环境/观察，不先调SAC超参、换任务或继续加训练轮数。

复用现有评估、外层进程更换与RLT回退。先备齐再在保存边界切换；不影响4/5和7，不为验证而修Isaac。全50×32噪声控制器/残差噪声是后续方法选择，不把noise_dim机械改1600冒充无需适配。

## DSRL是否必须高基础成功率

DSRL冻结原策略，只学选噪声。能较常采到成功，更容易知道哪些选择值得强化；若当前采样全失败，Q主要学到相似失败成本，不能指望仅多跑就自动恢复旧52%。但论文有20%提高到90%的案例，没有“必须超过50%”阈值。核心是当前接入条件下保有可探索的成功行为。

论文[§C.5重复噪声、§5.6基础策略质量](https://arxiv.org/html/2506.15799v2)；[官方π0代码](https://github.com/nakamotoo/dsrl_pi0)；[RLinf DSRL](https://rlinf.readthedocs.io/en/latest/rst_source/examples/embodied/dsrl.html)。这些支持设计来源，不证明Dojo适配已经有效。
