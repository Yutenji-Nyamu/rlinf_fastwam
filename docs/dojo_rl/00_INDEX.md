## 本轮最重要的发现

1. 历史Dojo π0.5 checkpoint seed1：扔瓶子 **26/50=52%**，叠碗 **12/25=48%**。这两个“seed”是官方模型/评估配置编号，不能当同一模型的随机重测。seed0对应成绩分别78%和80%。
2. 现有Dojo权重是JAX格式；训练用的RLinf是PyTorch。需要转换同一份Dojo权重并复核动作接口，不能拿RoboTwin权重直接替代。
3. 旧RLinf PR1606已被后续提案替换。当前PR1754仍未合并，明确只提供评估接入，文档写明RL训练尚未支持。
4. 当前上游桥接在多环境时每个环境启动独立Isaac进程，逐个请求并等待；其随机重置也没有使用传入的seed。它适合借鉴接口，不能直接当我们已验证的高并发、同初态GRPO训练后端。
5. 我们已跑通的Dojo原生25环境、任务报错跳过、精确清理、JAX策略接口要复用；训练新增的仅是可微策略、动作概率/更新与必要的环境训练接口。
