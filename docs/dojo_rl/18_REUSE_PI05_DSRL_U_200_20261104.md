## 方法增量确实很小，但不只是删一个repeat

1. **换任务配置**：adjust_bottle→turn_switch，真实动态指令/default prompt/训练验证种子与200上限同步。沿已有reset先更新场景再生成指令的修复。历史C50/400成功15/32不能当C20/200的起点评估。
2. **32维重复→50×32独立**：复用11/04已经跑通的`tools/dojo_offpolicy/full_noise.py`方法层，噪声actor输出1600、Q读取1600、回放存1600，最后reshape到原模型H50/D32。原VLA与动作反变换不改，不引入Dojo模拟器/RPC。
3. **完整噪声尺度**：目标熵−800、初始α.02、联合概率FP32沿当前完整版候选。它们是维数变化的显式适配；不能宣称只改采样而所有超参数字面相同。
4. **＋U两个明确兼容点**：旧模型初始化要求`dsrl_action_noise_dim == action_dim`（32），完整版需按开关检查H×D；旧U回放强制schema2，新增full+U用独立schema4（已有full Clean为3），载入时继续拒绝旧32维回放/优化器。不能把U检查直接关掉。
5. **同噪声U**：主N10和旁算N5都必须使用同一份完整[50,32]噪声，不能一支独立、一支重复；按配置重建C20信号spec，不沿helper默认C10。

正式只从原SFT和空回放开始，旧32维噪声策略/优化器/回放不跨维度续训。必要短测为Clean/full+U各一次真实采样→更新→完整保存恢复；沿已测micro256起步，不重新做大并发矩阵。显存不满不等于必须增加每轮采样预算。

## ＋U到底加在哪里

旧代码已经是**chunk级**：
1. 采样同观察/同噪声生成N10和N5，前C20、真实14维求逐动作相对分歧（population std/RMS）。主动作仍用N10。
2. 将这些逐动作U和有效标记存入该chunk回放；训练时读取该次历史采样的U，不为当前新latent重新旁算。
3. 每chunk有效位置的log(U+eps)求平均；在完整256样本batch内min-max后exp(score/τ)，归一化平均权重为1。
4. 每chunk一个权重乘噪声actor的整项`α·logπ−Q`。Q的TD loss、温度loss、奖励和回放抽样均不加U。

它不是1600个噪声坐标各乘权，也不是重新引入GRPO逐动作概率。τ越小差别越大；原τ2.5下未加trick前最大/最小权重比最多exp(1/2.5)≈1.49。
