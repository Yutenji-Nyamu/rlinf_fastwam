## 方法改了什么、依据谁

[DSRL附录C.5](https://arxiv.org/html/2506.15799v2#A3.SS5)说明π0的50×32完整噪声较难优化，作者用32维沿时间重复。[官方issue9](https://github.com/nakamotoo/dsrl_pi0/issues/9)有π0.5关节控制复现者报告完整噪声有效、重复噪声失败；也有重复版可用的报告。这给出尝试依据，不能当作Dojo必然提升的结论。

| 层次 | 具体实现 | 依据 |
|---|---|---|
| 原策略 | 同Dojo seed1/59999转换权重，臂关节变化量＋夹爪绝对值，冻结整个VLA | 已通过的Dojo模型/归一化/动作接口 |
| 噪声策略 | 重复版输出32维；完整版输出1600维，reshape为50×32，不复制、不打乱 | 完整噪声方案、官方对角高斯策略通用结构 |
| Q与回放 | 完整版保存/读取全部1600坐标；schema3隔离旧32维回放 | SAC必须对实际所选潜动作评分；旧实现首行压缩不能沿用 |
| 概率 | 完整版1600维联合log概率在FP32求和；参数仍bf16 | 避免大维度求和精度损失；梯度测试通过 |
| 目标熵 | 重复−16；完整−800，均为−维数/2 | DSRL目标熵规则 |
| 初始α | 重复1；完整0.02 | **本次尺度适配**：联合log概率维数增加50倍，初始系数除50，保持熵项与Q的初始量级可比；不是论文报告的完整噪声超参 |
| 其他SAC参数 | actor1e−4、Q3e−4、10Q均值、γ=.999、UTD20、global=micro256、预热500条转移、原奖励/终止逻辑 | 已接受ff64209 DSRL实配；不额外增采样量 |

核心增量是`tools/dojo_offpolicy/full_noise.py`，只对隔离的已验收源码导出应用。默认开关false，旧重复路径不变。动作策略、Q、回放一起改，避免“只删repeat，却只训练第一个位置”。
