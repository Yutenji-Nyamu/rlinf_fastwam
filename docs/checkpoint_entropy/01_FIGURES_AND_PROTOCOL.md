# 图要回答什么

## 1. 熵与师生距离

每个位置对应同一个观察、同一查询chunk、块内同一动作坐标。学生4噪声的离散程度估计学生熵；学生第0份与教师同噪声第0份的14维RMSE为动作距离。因此已有教师K1足够算距离，不能用这两个不同策略的单次动作差代替教师自身的熵。

主图横轴动作距离、纵轴学生熵：二维密度图显示全部位置，等量分组均值显示趋势。附逐轨迹相关、成功/失败分层、前后query及块内h分层；置信区间按完整轨迹重抽，不能把相邻几千动作当几千个独立样本。保留不除动作幅值的主指标和旧相对分散度作敏感性分析，不根据哪张图更漂亮更换主定义。

四份学生输出中的第0份也参与距离，可能产生共同噪声影响：用剩下3份学生估计熵再画同一距离，仅作敏感性对照。多模态的多个有效动作也会产生大分歧，动作距离不是错误标签。

本轮现有药瓶数据重算：熵与距离Spearman 0.415；整轨迹bootstrap（500次，固定seed1102）95%区间[0.240, 0.565]。排除主噪声后K3熵相关0.409；旧相对分散度相关0.083。当前正关联有数据支持，指标定义也明显影响关系强度；这些仍只有32条轨迹，不是多任务结论。[三种读图方式](http://127.0.0.1:8194/entropy1102/)。

## 2. 两策略高熵位置是否一致

教师也对原来的四份噪声预测。已有第0份保留，只补另外3份。固定全部有效位置，各策略独立选最高20%，交集大小除以入选数量。1000位置各选200、重合160，就是80%；独立随机集合的期望约20%。并列按固定位置ID打破。

这张表测的是两者是否在相同位置不稳定，不要求动作相同。每策略只有一次预测时，自身分散程度无法估计。

## 3. 哪类动作熵变化较多

只用学生（或同run初始模型）的熵排一次序，分成十等份。固定组内位置，画教师减学生（或末代减初始）的平均值。正柱表示更分散，负柱表示更集中。不能每个检查点重新分组后当成相同位置，也不预设正负趋势。

## 4. 同run训练演化

初始、最接近20/40/60/80%、最终，共六个真实检查点；以最终策略采一次固定观察池。各点读同一池、同四噪声，输出逐位置熵。横轴真实训练步，画50/80/95百分位；同一池另做Base/Final重合率及十组变化。

现有Clean140/Uτ3CP70是两条不同run；现有观测由Clean140执行，因此不能标成同run演化或“最终策略生成”的观察池。

## 指标及参考的边界

沿用写作revision_03/04：归一化模型动作14维、K=4、逐坐标无偏方差（ddof=1），`H=0.5*sum(log(2*pi*e*(var+1e-6)))`。这是对角高斯熵估计；原方差、动作、噪声保留，负熵可正常出现。K4是既有采集预算，不是充分拟合任意多模态分布的保证。

K4估计本身有噪声，可能让Top20位置不稳定；用初始K4分最高组后再看变化，也可能包含回归均值。主协议先固定、不追加大矩阵；得到结果后若要解释为训练机制，再用小部分固定观察的第二组独立K4检验排名及分组稳定性。跨检查点共用噪声有助于配对，但不会自动消除上述问题。

- [Beyond the 80/20 Rule, NeurIPS 2025, §4](https://arxiv.org/html/2506.01939v2#S4)：用最终策略生成的固定内容比较训练检查点，Top20%重合及初始熵分组。借固定输入/位置的分析逻辑；其原指标是LLM token概率熵，原分组5%，本项目按写作要求10%。
- [FIPER §4.2、A.1](https://arxiv.org/html/2510.09459#S4.SS2)：同观察采多个动作块，逐预测位置估熵，支持本项目逐位置组织方式。原ACE使用离散分箱并研究多模态；我们的K4对角高斯公式不是原ACE的直接复现。
- [UA-OPD](https://openreview.net/forum?id=hHUZi8oHfo)的教师不确定性与奖励误差图用于读图参考；这里RMSE是策略分歧，不改叫reward gap。
