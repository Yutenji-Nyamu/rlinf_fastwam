# GAD K4执行合同（2026-11-01）

用户选定四噪声标准差＋师生动作差异，覆盖Direct、DMD new、MFD、CP v2；新建实验，从各自同一原始基座开始，不改现有运行。前期权重扰动等研究仅留作候选，不属于本次实现。

## 逐项依据与改动

| 项目 | 实际选择 | 依据与界限 |
|---|---|---|
| 模型、数据 | 原生RLinf adjust_bottle π0.5；50示范/4738完整H50窗口，冻结VLM只训AE | 已验收single_formal；不是Sidney多任务基座 |
| 老师/学生 | N5/N1，内部H50×32；信号只读真实14维；评估C50、200动作、128回合 | 原生模型实际配置，保持既有单任务对照 |
| 模型内信号 | K4独立标准高斯噪声，逐动作逐维population std，再平均14维 | 复用noise_samples.py的独立噪声、固定观察路径；标准差是分散度代理，不声称概率熵或错误概率 |
| 模型间信号 | 同观察、同一份噪声，师生动作RMS距离，再平均K4 | PIVOT-Q paired_flow固定噪声思想；从其块/首动作扩展为50动作位置 |
| 信号坐标 | 老师归一化后的绝对关节动作14维，夹爪同其归一化 | endpoint_loss现有坐标；不除以动作模长，避免接近零放大 |
| 合成 | 对D、学生std、老师std分别作同批tie-aware百分位，q=(rankD+rankUS+1-rankUT)/3 | PIVOT-Q的rank去尺度；LLKD/DWA-KD的老师可靠、学生有改进空间方向；等权三项是本次工程选择 |
| 动作权重 | w=0.5+rank(q)，严格介于0.5～1.5，均值1；所有同值时w=1 | 延续历史DVAC的正、有界介入；PIVOT-Q有界权重参考。数值不是文献证明的最优值，避免压缩到几乎不介入或硬筛除 |
| 抽样 | 50%均匀＋50%按窗口优先级百分位^0.6；优先级为最近一次块内q均值，同步两rank；未见窗口=0.5 | PER的随机优先级、概率幂和IS；0.6来自其proportional对照，原rank版本是1/rank、α0.7。本次采用百分位平滑，是明确的温和适配，并非原PER rank公式。保留任务均匀先验 |
| 抽样校正 | 使用抽取当时P，乘P_base/P，β=1 | PER importance correction；避免抽样、loss权重重复叠加。校正≤2，动作w单独仍0.5～1.5；最终乘积不能误报仍有相同界 |
| Direct | 对每动作14维MSE加权，目标仍是一次普通配对噪声的老师端点 | endpoint原实现；不把K4教师均值当动作标签 |
| CP v2 | 一致性与FM两项按相同位置权重加权；14维、原Huber公式/EMA保持 | 已验收cp_v2；不额外添加dropout或改变两项系数 |
| DMD new | 有符号surrogate在坐标均值后加权；辅助epsilon MSE也按位置加权 | 原onedp代码、学生14维/辅助32维保持；不是静默换dmd_v2。权重detach，不通过信号反传 |
| MFD | 平均速度surrogate与辅助velocity MSE同样加权 | 原MFD平均速度积分、步长0.02、辅助32维保持；不静默换mfd_v2 |
| 学习参数 | Direct/CP原AdamW、LR 2.5e-5与原warmup；DMD/MFD学生1e-5辅助2e-4、5:1、clip1 | 历史single-formal和用户指定DMD new；MFD5:1是既有适配，不称官方10:1 |
| 训练预算 | 各400预算轮；从基座开始；继承原0–100密集评估＋120…400每20轮128回合 | 现有四方法的累计预算与评估口径；Direct显式复现100→200→400、CP v2复现200→400的余弦终点切换，优化器状态不重置，避免方法外时间表差异 |
| 并行 | 先沿用实测Direct224、CP80、DMD/MFD192每卡；双卡。信号K4串行四个合批，共享已缓存前缀 | 不是逐样本推理；不复制4份大KV占用。若OOM只减micro并累积，保持global batch和总更新数 |
| CPU供数 | 8线程解码，一步提前；采样在主线程；checkpoint保存优先级、访问计数与下一批id/P | 既有prefetch实测8线程；避免线程时序改变恢复后抽样。辅助5轮共用一次信号 |
| 保存/错误 | 每组仅最新完整续训点；smoke成功后权重大文件不作正式依赖；错误记账后接下一方法，尾部RLT保留无保存兜底 | 用户滚动保留与持续占卡偏好，复用现有队列生命周期 |

## 预先声明的命令、资源与验收

## 参考

- [PER, ICLR2016](https://arxiv.org/abs/1511.05952)：优先抽样及importance correction，不等于原论文已证明GAD有效。
- [PIVOT-Q](https://arxiv.org/html/2610.05745)：配对噪声、rank组合、有限权重；固定源码 `2dc126a` selection.py和paired_flow.py已核。
- [LLKD, NAACL Findings2025](https://aclanthology.org/2025.findings-naacl.142/)：老师/学生双信号选择；原信号是分类置信度，本次迁为动作分散度。
- 历史本仓库 `dvac_train_weighting.py` 使用正且有界权重、detach；仅作为工程先例，不能把历史成功归因到某一界值。

本轮首先验证可运行、幅度适中、额外耗时；性能收益由完整对照评估判断。记录等样本与wall-clock，额外K4前向不能隐去。

## 介入幅度为何不是硬筛选

三种信号先各自排序，合成后再次排序，保留高/低顺序但不让异常数值主导。连续信号时权重标准差约0.289、有效样本比例约92.3%；最高/最低相差约3倍，平均梯度规模维持原量级。相同信号均给权重1，不人为按样本编号打破平局。

抽样相对均匀的概率至少0.5倍，理论至多1.5倍，普通无平局时最高约1.3倍；概率差可约2.6倍。每轮预算仍按原样本数计算。使用固定β=1对照PER完整IS（其图12），保持原学习率；这不等于声称依赖当前batch的GAD权重拥有固定无偏目标。
