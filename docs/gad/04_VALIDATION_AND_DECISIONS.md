# 最小验证、原始产物与下一步

2026-10-31，尚未启动。

## 原始数据和图分开

沿用现有signal collector的同观察、噪声ID、实际执行步数、视频与动作映射约定，新增字段不重写整个采集器。训练信号分析和机器人评估分开。

原始小样应保存：

- task/episode/window/query/action位置、模型checkpoint、H/C/老师N、正常和扰动噪声seed。
- 正常师生端点与各扰动端点 `[B,K,H,14]`，动作归一化身份、单位/实际维mask。
- 扰动类型、位置、rank/幅度、固定还是刷新、模型未改变验证结果。
- D/U_T/U_S原值、valid、分位数/权重、priority/采样概率/更新时间。
- 若涉及GEO/DV，仅多步模型保存真实速度/内部端点及时间网格；一步对应valid=false。
- 训练主要留轻量统计和有限诊断窗口，完整录像仍仅给专门信号采集；不把所有训练轮变成信号录制。

当前10/31采集是**同一原始多任务模型的N1/N5/N10旁算**，可研究步数近似差异；10/29接管信号是**pillbottle两个RL权重**。这两者都不是正在训练的GAD学生，不能直接拿其相关性证明蒸馏学生的U有学习价值。

## 验证优先顺序

1. 信号层：在少量既有示范窗口/已有成功失败轨迹观察上比较候选，先不训练；固定噪声、原输出不变、各动作单位一致。只在未来授权资源上做GPU验证。
2. 看是否有新增信息：D与各U散点、分位箱；同时按轨迹/任务/块内位置分组；控制D与动作幅度后，U是否仍与已有失败标记或留出误差相关。
3. 不循环论证：用D定义权重再报告“权重高处D更大”是必然结果；真正需要看留出误差改善、评估成功率和wall-clock。
4. 权重模块：w全1严格复现Direct，零扰动与原输出相同；评分无梯度、14维掩码有效。随后只做少量训练/续训检查。
5. 抽样模块：只核任务配额、ID和概率、断点续抽；不额外全盘加载数据或重复校验大权重。

## 建议消融的最小逻辑

Direct → 仅D权重 → D＋U_T＋U_S权重 → 加优先抽样。

不必一开始把所有候选信号都做成长训练。先用有代表性的固定窗口筛出信号有变化且成本合适的一两个；然后按同一老师/同一任务/同一预算比较。若信号值大多恒定、只跟动作大小走、或开销过大，就停止该支路。早期曲线仍沿用已经接受的密集评估节奏。

## 下一轮需要收敛的选择

1. 主信号：优先模型扰动，还是更低开销的STAC/特征覆盖度？四噪声作对照。
2. 若模型扰动：原文VLM位置还是动作专家位置；先保留两者小样对比，不默认省计算版等价。
3. 训练基座：建议从现成单任务Direct实配做首个可解释对照，后扩多任务；若用户要直接多任务，则继承多任务Control的N10/H50/C10等，不混单任务N5。

本轮不需要用户逐项批参数；选定信号和第一套Control后，再按已有smoke经验给出有限候选和代价。

## 摘要应同步调整

当前可准确描述的目标：**结合师生动作分歧与一步兼容的不确定性代理，进行动作级监督分配和动作块优先采样。**

“高师生分歧对应关键阶段”“低老师U代表监督可靠”“高学生U意味着更大可改进潜力”都是待检验假设。此前RL接管的高低U结果不能直接替代这些证据。

采用参数扰动或特征覆盖度后，摘要不要仍写“学生去噪速度变化”；GAD是否保留Geometry含义需随后解释清楚。当前没有GAD仿真/实机结果，不写已获一致提升；OpenWAM/CD/DMD是计划扩展，不是已验收的即插即用范围。
