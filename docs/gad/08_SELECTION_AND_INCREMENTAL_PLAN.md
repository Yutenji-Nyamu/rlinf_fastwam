# GAD信号选择：当前收敛与下一轮讨论

2026-10-31。候选方案，尚未选定/实现GAD，不改变当前实验队列。

## 推荐顺序

1. **权重扰动输出分歧**：不同于旧多噪声；教师和一步学生都可定义。用PFD做π0.5接口依据，TokUR做低秩参数变体参考，TFB做幅度标定参考。首先选择扰动VLM还是动作专家，不能隐去此差异。
2. **动作专家特征覆盖度**：KNN/PatchCore作便宜对照；无需额外生成完整动作，但需要各自参考库和防自查。
3. **观察轻扰动**：借SPUQ/TTA，测图像稳健性；输出分散仍用真实动作坐标，固定动作噪声。
4. **前后计划重叠**：适用于H>C且有相邻观察的材料，更多解释执行中的计划变化；不把当前H50/C50采集直接当作已有数据。
5. **MC dropout**：方法成熟，但当前老师/Direct学生没有对应训练条件。后续若引入需单独命名版本。
6. **内部特征谱**：LLM-Check式低采样候选，机器人证据弱、逐动作解释较难，放探索层。

选择信号无需同时叠满上述项目。当前首推“权重扰动＋一个便宜特征对照”，四噪声作为已有参照，便于判断新信号究竟增加了什么。

## 权重扰动的具体定义草案

对同一观察o与生成噪声z，分别生成K个模型变体的动作：

`A_T[k] = teacher(o, z; theta_T + delta_T[k])`

`A_S[k] = student(o, z; theta_S + delta_S[k])`

- 对每个未来动作位置h，仅取14个有效动作坐标，求跨变体方差或成对距离，得到U_T[h]、U_S[h]。主指标先采用绝对分散，不除以可能接近零的动作均值；动作归一化沿用基线。
- 每个delta在一整个动作块生成过程中固定。不同输入、不同训练步可以重用种子或重新抽取，但需固定实验定义。
- 正常老师目标与学生执行动作仍来自无扰动模型；K个变体只生成信号，均detach。
- K、秩、位置、幅度尚未确定。K4可复用旧采集的合批方式，但不是已经选定的新默认；先有限样本比较成本与排序稳定性。
- 相同随机种子/数值sigma并不保证师生受到相同有效扰动。至少记录相对权重改变量和平均动作漂移；U_T/U_S先在各自参考分布内转分位数，不直接比较未经标定的原始数值。

### 幅度怎么选

借TFB原则，准备小份固定参考观察：增加扰动时，比较原模型与扰动模型的有效动作漂移；若有专家动作，可另记模仿误差变化。用明确的容差筛掉已明显破坏预测的强扰动，随后检验剩余候选的信号是否有区分力。

这是连续动作的适配校准，不是TFB原NLL后验。学生变化后需低频复查，不能每次更新都做完整搜索。幅度过小可能只有数值噪声，过大只是在测坏模型；也不应逐样本调幅到相同漂移，那会把要测的差异主动抹掉。

## 把信号用到GAD的分工

|部分|直接依据|我们的最小变化|
|---|---|---|
|师生分歧D|已有Direct同噪声端点MSE；PIVOT-Q动作分歧选择|保留逐动作误差，不提前平均H|
|老师低U优先信任|UA-MT可靠位置筛选，BootsTAP循环筛选伪标签|冻结老师目标，分数只控制权重，不反向通过信号|
|学生高U优先练习|主动学习对不熟悉样本的查询；DBAL/Core-set提供不同角度|这是待验证的蒸馏优先级假设，不能把主动标注收益直接当作蒸馏收益|
|优先采样|PER的抽样概率/偏差校正接口|保持任务均衡；与loss加权拆开，防止重复放大|

**高分歧不等于可靠监督。** 如果老师、学生都对场景不熟悉，把这部分大幅加权可能放大错误。反过来，老师低U也可能稳定地错。因此第一步看信号是否比已有D更能区分有用监督，而不是先把多个量相乘。

## 最小分析材料

复用现有图像/状态、任务/轨迹/窗口ID，固定观察与动作噪声；记录正常师生动作、变体动作、扰动种子/尺度、有效动作mask、信号，以及实际耗时/显存。不需要重新采一套全任务视频才能比较模型信号。

分别看：

- 同任务同阶段内，U是否与师生误差、持出示范误差有关；不要把50任务难度差异误认成动作级关系。
- 控制动作大小/未来位置后，关系是否仍在；既报告前C段，也报告完整H，不擅改训练监督段。
- 以轨迹为单位划分参考/验证，按轨迹而非每个动作独立估计统计波动。
- 在相同额外计算预算下，比较权重扰动、四噪声、特征覆盖；不能只比K而忽略前缀重算。
- 图像增强或权重扰动的旁算不应改变原动作、生成随机状态及实际执行路径；只做一次必要回归检查。

正式训练仍先接Direct做权重对照；CD/DMD的“即插即用”适配需要各自目标/梯度分析，不能在摘要中提前写成已验证。
