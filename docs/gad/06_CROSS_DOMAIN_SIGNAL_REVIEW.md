# 一步策略的不确定性：跨领域参考

2026-10-31。研究/规划；本轮没有运行上游代码、修改训练或启动GPU任务。按原始论文、正式会议页和作者代码核对；论文效果不是我们的复现结果。

## 先分清问题

“一步”只限制一次生成动作的去噪次数，不妨碍对同一个观察做几次独立前向。我们要区分：

|信号|固定什么、改变什么|主要反映|不能直接解释成|
|---|---|---|---|
|权重扰动|观察、生成噪声固定；轻微改变模型|预测对模型参数的敏感性|精确失败概率、已校准的贝叶斯后验|
|输入扰动|模型、生成噪声固定；稍改图像|对观测变化的敏感性|纯粹的模型不确定性|
|前后计划一致性|对齐同一未来动作时间；使用前后观察|重规划改变程度|改变计划一定错误|
|特征覆盖度|模型正常前向；与参考特征库比较|熟悉程度/分布外程度|学生还需要学多少|
|MC dropout|固定输入/生成噪声；随机关闭特征|在已有dropout训练假设下的模型分歧|给任意旧网络临时加dropout就有可靠U|

熵不是LLM专用概念；医学分割也用类别熵。此处过滤的是依赖词表概率、Yes/No回答或语义裁判的具体实现。π0.5直接输出连续动作，先用14维有效动作的方差/距离更直接；不把四样本分散度改名为精确熵。

## 1. 权重扰动：重点候选

**直觉：**同一张图、同一份动作噪声，模型参数轻轻变一下，动作就大变，说明这个决定对模型细节很敏感。旧四噪声改变的是动作生成起点，测到的还包含合理的多种做法。

|论文/级别|怎样得到信号、怎样使用|对我们的价值与限制|
|---|---|---|
|[TFB，NeurIPS 2025](https://proceedings.neurips.cc/paper_files/paper/2025/hash/3b7fb63a8584681c73433f019c27f936-Abstract-Conference.html)|把已有LoRA变成低秩随机权重；在参考样本上搜索可接受的最大方差；多次预测用于校准与预测平均|主要借“先标定扰动幅度”；我们是完整动作专家微调，不是LoRA；不直接照搬其公式/阈值|
|[TokUR，ICLR 2026](https://openreview.net/pdf?id=VHQc7wzmYv)|对注意力Q/K权重加低秩扰动；评估同一文本前缀的预测分歧；筛选、加权候选推理答案|其SVD方向扰动适用于已有完整Linear；借生成模型变体的方法，丢掉token熵/语言投票；正常生成用均值权重|
|[SWAG，NeurIPS 2019](https://papers.nips.cc/paper/2019/hash/118921efba23fc329e6560b27861f0c2-Abstract.html)|从训练后期权重轨迹统计均值和低秩协方差，再抽模型预测|说明扰动方向可来自真实训练轨迹，不一定任意高斯；需额外统计、训练日程，固定老师未必有这些材料|
|[PFD，2026预印本](https://arxiv.org/html/2606.20754v3)|同动作噪声下，扰动π0.5视觉语言部分，比较终点动作；时间聚合后检测失败|最直接的π0.5接口依据；原位置为VLM MLP down projection，不是动作专家|
|[SAVE/VFD，2026预印本，附录B.5.5](https://arxiv.org/html/2606.18043#A2.SS5.SSS5)|主方法是独立模型流场分歧；附录另测试权重扰动|SmolVLA真实任务设置里，只扰动动作专家最高balanced accuracy 0.62，联合扰动约0.66–0.68；不能把省计算方案视为等价|

TFB的“不训练”是不用再做梯度优化，仍需参考样本前向搜索。论文§3.3允许标注、伪标签和无监督参考指标；保留参考指标不等于保证机器人成功率不变。建议借其校准原则，不把我们的简单输出漂移约束称为TFB后验推断。

**可行适配：**权重扰动只走旁路，实际动作/Direct监督目标仍用原始模型；固定一次扰动直到老师整段去噪结束。先保留逐动作分歧，不先压成一个块均值。动作专家扰动便宜，VLM扰动需要重新计算图像/语言前缀；这两种位置应明确分开。

## 2. 输入扰动：LLM有很直接的类比

**直觉：**同一个问题换种说法，或者同一个场景稍变亮，模型是否仍作相近决定？

|论文/级别|信号和用途|迁移要点|
|---|---|---|
|[SPUQ，EACL 2024](https://aclanthology.org/2024.eacl-long.143/)|改写问题、系统提示、无关符号或温度，多次回答并聚合一致性，估计回答可信度|借“保持含义的输入扰动”；文本相似度、语言自报置信度不能直接用于连续动作|
|[TTA + post-hoc calibration，AAAI 2023](https://ojs.aaai.org/index.php/AAAI/article/view/26735)|多种增强图像的logit平均后再校准，改善图像分类与皮肤病判断的可信度|原方法不是简单计算方差；可借输入响应思想，不能把我们的动作方差说成复现其校准|
|[TTA + conformal prediction，CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Shanmugam_Test-time_Augmentation_Improves_Efficiency_in_Conformal_Prediction_CVPR_2025_paper.html)|学习增强聚合，再用独立校准集构造更紧的预测集合|适合以后设拒绝/接管阈值；没有独立校准数据及相应假设，就没有相同覆盖保证|
|[Wang等，Neurocomputing 2019](https://arxiv.org/abs/1807.07356)|对医学图像做变换；把分割结果变换回原坐标，统计像素预测分布|给出观测噪声U的直接依据；几何变换后必须对齐输出，不能把“旋转图像但关节指令不变”当普通增强|

对π0.5，先考虑轻微亮度/对比度，保留任务颜色和物体几何；动作生成噪声保持相同。需要重新做视觉前向。我们的“老师可靠性”不一定是视觉鲁棒性，因此它适合作为独立对照，不与权重扰动分数混称同一U。

## 3. 前后计划一致性：外领域有“循环检查”，也有不同的“时间集成”

**机器人例子：**旧块预测动作1–50，执行1–10后，新块预测11–60；比较旧11–50和新11–50，而不是比较两个块相同数组下标。[Sentinel/CoRL 2024](https://arxiv.org/abs/2410.04640)是最直接依据。

- [BootsTAP，ACCV 2024](https://openaccess.thecvf.com/content/ACCV2024/papers/Doersch_BootsTAP_Bootstrapped_Training_for_Tracking-Any-Point_ACCV_2024_paper.pdf)：视频追踪同一个点，换个时间作为起点后应回到原点；循环对不上的轨迹不参与相应伪标签训练。借的是“用一致性检查筛可靠监督”。
- [UFlow，ECCV 2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123470545.pdf)：利用遮挡/前后光流一致性处理无效监督，并强调停止遮挡mask的梯度。这里是图像像素对应关系，不是机器人的控制计划。
- [Temporal Ensembling，ICLR 2017](https://openreview.net/pdf?id=BJ6oOfqge)和[Mean Teacher，NeurIPS 2017](https://proceedings.neurips.cc/paper/2017/hash/68053af2923e00204c3ca7c6a3150cf7-Abstract.html)：在训练迭代之间平均预测或权重，构造稳定目标。它们的“时间”是训练历史，不是执行前后重规划，也不是自动得到失败检测分数。

我们只有在C<H时才有重叠。当前已授权N步信号采集继承H50/C50，没有相邻块重叠，不能从现有两块直接算40步重叠分数。H50/C10的其他评估/训练协议可另外评估此量。独立窗口训练要补相邻观察与严格时间对齐；看到新信息后正确地改变计划也会使分数升高。

没有找到足够直接、可照搬的“滚动时间序列预测修订量=模型不确定性”近期顶会方法；不拿预测区间/时间序列校准论文冒充这一机制。

## 4. 特征覆盖度：工业质检是很好的直觉

**直觉：**先记住正常零件/熟悉示范的内部特征，遇到新输入时找最相似的几个；距离还很远就说明不熟悉。

|论文/级别|怎样用|迁移边界|
|---|---|---|
|[KNN-OOD，ICML 2022](https://proceedings.mlr.press/v162/sun22d.html)|对归一化特征求第k近邻距离；检测训练分布外输入|最简单的低成本基线，不增加可训练网络；仍需参考库与k选择|
|[PatchCore，CVPR 2022](https://arxiv.org/abs/2106.08265)|正常图像小块特征库＋代表性子集；定位异常零件区域|可借“局部特征得局部分数”；将图像patch换成动作位置token是我们的适配|
|[DDU，CVPR 2023](https://arxiv.org/abs/2102.11582)|在受约束的特征空间拟合类别高斯密度；OOD检测、主动学习|原模型有残差/谱归一化等条件；不能保证任意π0.5隐藏层距离天然可靠|
|[HyperDUM，CVPR 2025](https://arxiv.org/html/2503.20011v1)|把特征投影并汇集为高维原型，用与原型的差异估计U，调整相机/雷达等融合权重|近期特征级U与干预实例；完整方法含可学习融合模块，不是无改动插件|
|[Core-set，ICLR 2018](https://openreview.net/pdf/e03df38b7410cbd2c6a27c4578c872e0dc1ce300.pdf)|选择能覆盖特征空间的样本去标注|适合我们“少重复、多覆盖”的采样参考；覆盖距离本身不等于概率U|
|[Post-hoc VLA UQ，2026预印本](https://arxiv.org/html/2610.29730)|基于参考特征的核条件方差，无需训练新神经网络|最接近当前VLA；统计头和特征库仍需建立维护|

**本项目特殊问题：**师生共享冻结VLM，读同一前缀会得到相同分数，不能区分老师和学生。读各自动作专家特征可以区分，但学生变动后需刷新参考特征；训练窗口必须排除自身及同轨迹近邻。库中全是正在训练的专家状态时，“离训练分布远”与“学生尚未学会”并不相同。

DUE也有回归代码及单次前向U，但其仓库自引为2021预印本，本轮只确认NeurIPS 2021 Bayesian Deep Learning workshop版本，未将其写成ICML主会论文。它需要特征约束/GP训练，不列首版直接插件。

## 5. MC dropout：经典依据与“怎么用于训练”的直接参考

- [MC dropout，ICML 2016](https://proceedings.mlr.press/v48/gal16.html)：训练已有dropout的网络，推理仍随机关闭一部分特征，多次预测估计分散程度；覆盖分类和连续回归，不依赖LLM。
- [Deep Bayesian Active Learning，ICML 2017](https://proceedings.mlr.press/v70/gal17a.html)：使用此类模型不确定性挑选值得获取标签的图像，包括皮肤病图像；借的是采样用途，其分类信息量公式不直接照搬。
- [UA-MT，MICCAI 2019](https://arxiv.org/abs/1907.07034)：老师是学生的EMA副本；老师做8次带dropout和输入噪声的预测，形成逐体素不确定性；只在可靠位置计算师生一致性损失。源码确实有训练dropout，并非仅调用train模式。

**UA-MT与GAD关系最直接的是“老师可靠位置才重监督”这一步。** 原方法使用分割类别熵；我们可保留筛选/加权逻辑，另选连续动作信号。它没有同时证明“学生高U越应加权”，这部分仍是我们的假设。当前Direct动作专家没有相应训练过的dropout，因此首版不建议临时插入并冠以经典MC-dropout校准解释。

## 6. 额外可选：一次前向的内部结构分数

[LLM-Check，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/3c1e1fdf305195cd620c118aaa9717ad-Abstract-Conference.html)对一次回答的隐藏特征矩阵计算谱统计，检测幻觉，无须再生成多个回答。这不依赖词表概率；可作为“动作专家50个位置特征的结构分数”探索，但它可能更多反映动作复杂度，且原分数是整段级而非逐动作U。

其Attention Score利用自回归注意力的下三角性质；π0.5动作段并非相同因果掩码，不能直接把注意力对角线当特征值。Hidden Score也要明确轴与中心化，原论文简式和公开函数实现不是随意可互换。

[INSIDE，ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/file/0d1986a61e30e5fa408c81216a616e20-Paper-Conference.pdf)则比较**多次回答**的隐藏特征协方差。它与旧多噪声采样相近，不作为摆脱多采样的新首选。[Query-level UQ，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/3a07c3a67cfe50d3236b71fb674c7f30-Abstract-Conference.html)虽一次前向，但仍读Yes/No等词表判断，本轮过滤。

## 参考选择结论

优先讨论：PFD/TokUR的模型扰动；TFB的幅度标定；UA-MT的可靠监督筛选。便宜对照：KNN/PatchCore特征覆盖。输入扰动独立保留；时间重叠限有相邻观察的协议；MC dropout与LLM-Check暂作后续选项。

这些依据分工不同：**怎么造信号、信号预测什么、如何用信号改训练**应分别验证，不能拼成一个已被论文证明的GAD配方。
