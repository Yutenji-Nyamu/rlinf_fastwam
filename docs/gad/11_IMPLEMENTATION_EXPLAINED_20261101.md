# GAD：实现与参数的通俗说明

2026-11-01。四个版本已完成GPU短测和队列注册；当前只有Direct＋GAD产生正式评估。精确公式、来源和验收见[执行合同](09_IMPLEMENTATION_CONTRACT_20261101.md)、[短测](10_SMOKE_AND_QUEUE_20261101.md)。

## 一次训练发生什么

1. 从固定50条调瓶子示范、4738个动作窗口中抽一批；不会在线增加示范。
2. 对同一观察，师生使用同样的四份随机噪声，各生成四份动作。老师N5、学生N1；每份预测50个动作。
3. 每个动作算三个数：学生四份动作的标准差、老师四份动作的标准差、配对师生动作的距离。只看真实14维，采用原生归一化坐标；不是概率熵，也不除以动作模长。
4. 倾向多学“师生分歧大、学生摇摆、老师稳定”的动作。三个量各自排序后等权组合，再映射成0.5～1.5倍，均值1。权重不参与反向传播。
5. 各方法仍用原来的训练目标，只在逐动作汇总之前乘权重；四噪声用于打分，不把老师四次结果平均为标签。
6. 记住这一窗口的优先级。下一次一半均匀抽、一半按优先级抽，同时乘抽样概率校正，避免“抽得多又多乘一次”无控制叠加。尚未访问的窗口用中性值，优先级随访问刷新。

例如，同一批里某个抓取动作的师生分歧大、学生不稳而老师较稳，它可能得到1.4倍权重；较容易或老师本身分歧大的动作可能得到0.7倍。仍保留全部动作和均匀抽样机会。老师稳定也可能稳定地错，这一信号只能作为可靠性代理。

动作权重0.5～1.5与概率校正是两层；乘积可以超出此范围，正式日志已单列。采用完整概率校正后，优先抽样主要改变频率、方差；额外强调来自动作loss权重。不能将依赖当前batch排名的整体方法简单宣称为某个固定目标的严格无偏估计。

用户指定基于DMD new和旧MFD，故学生仍14维、辅助仍32维；没有静默换成v2。CP使用已完成的v2。均冻结VLM、训练动作专家，H50/C50、200动作上限；27次评估，每点128回合，不录像。与多任务Sidney N10实验协议分开。

学习率、优化器、梯度裁剪、预算和评估点继承各自已跑通的原对照。Direct复现100→200→400轮的衰减终点变化，CP v2复现200→400，避免无意改变原方法外设置。每组只保留最新完整续训点，旧点只在新点写完后滚动淘汰，保留所有曲线与小日志。

## 哪些来自论文，哪些是本次选择

- K4配对、信号原始动作路径：已验收的四噪声采集。这里是同一个模型的随机输出分散度，不是四个独立模型。
- 师生同噪声比较、排序去量纲、有界权重：借鉴[PIVOT-Q](https://arxiv.org/html/2610.05745)。原任务是量化，迁到逐动作蒸馏属于适配。
- 结合老师可靠性与学生学习需求：借鉴[LLKD](https://aclanthology.org/2025.findings-naacl.142/)的方向；它的分类置信度与我们的动作标准差不同。
- 优先抽样、概率幂、importance correction：依据[PER](https://arxiv.org/html/1511.05952v4)。0.6源自其proportional设置；本实现的“百分位^0.6＋50%均匀”不是照搬其rank公式。
- 三项等权、0.5～1.5、50/50混合：结合历史有界加权经验作出的适中工程选择，不能称论文证明的最优强度。排名依赖相对位置，即使绝对差异较小也可能拉开权重；日志保留绝对信号以便判断。

## 并行、耗时和当前证据

四版直接沿用已有大batch，短测12→14续训及导出N1/B32通过；峰值72.5～74.2GiB/卡。四噪声使用四次合批调用，共用视觉语言前缀；不是逐样本推理，也不复制四份大KV缓存。8线程解码、提前准备一批、辅助5次共用同一批信号。

11:07正式Direct：约8.18秒/更新，其中观察前缀约3.53秒、K4信号约3.49秒、学生更新1.09秒，供数等待约0.008秒。新信号约占43%，后续应同时比较相同样本预算和相同耗时。优先级更新约1毫秒。

最新140轮104/128=81.25%，原Direct同轮105/128=82.03%；仅差1回合，目前没有清晰增益。其余新GAD只有短测，尚无正式成功率。完整实测点表见[本次回执](../experiments/review-20261101a/README.md)。
