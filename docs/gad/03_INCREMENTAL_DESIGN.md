# GAD相对已跑通Direct增加什么

2026-10-31，设计稿。下面的公式与参数是我们根据参考机制提出的适配，尚未部署。

## 1. 继承实际基线

现有 `rlinf/algorithms/pi05_distillation/losses.py::endpoint_loss` 已经在同观察、同噪声下计算老师端点和学生一步端点：

```text
示范窗口 → 原预处理与冻结视觉语言前缀
             ├→ 多步老师终点 a_T（无梯度）
             └→ 一步学生终点 a_S（有梯度）
前14维逐元素平方误差 → 全H50平均 → 更新学生动作专家
```

模型内部H50×32保持，评分只用14个真实坐标。维度、动作归一化与C保持原Control；不把换信号同时变成只监督前C步。单任务原生adjust_bottle基线老师为N5，多任务Sidney为N10，按实际Control继承，不静默统一成N10。

当前入口：

- `model.py::Velocity.forward/endpoint/prepare`：共用固定视觉语言前缀；只有动作专家及相应投影参与学生训练。
- `losses.py::endpoint_loss`：保留 `[B,H,14]` error，末维平均先得到 `[B,H]`，延迟全局reduce以接权重。
- `tools/pi05_distillation/train.py`：仍用现成训练、保存、续训与评估分段。
- `prefetch.py::training_indices/decoded_batches`、`data.py::MultiTaskDataset.indices`：未来优先抽样只改窗口索引；数据内容、解码池、任务均衡复用。

## 2. 信号单独做接口

同一窗口i、动作位置h：

`D_ih = sqrt(mean_14((a_S - a_T)^2))`

同一观察和初始动作噪声，排除两者随机抽样不同产生的额外差异。用老师既有归一化坐标；另记关节/夹爪分项。它是耦合动作距离，不是完整分布KL，也不自动等于失败风险。

一个可选的一步共同信号：

`U_M,ih = mean_14(Var_k a_M(o_i, z_i; perturbation_k))`，M∈{T,S}。

对权重/观察扰动，固定z；对四噪声对照，固定模型/观察、改变z。**把两种随机性分开**。所有原始值保留，权重分支detach；只让未扰动学生的正常端点损失反向传播，防止学生通过改变权重而非学会动作降低loss。

拟新增 `signals.py` 返回 `D,U_T,U_S,valid,provenance`；扰动策略独立adapter。零扰动时需回到原模型输出；不得在optimizer持有的参数上原地加减扰动。对低秩Linear扰动可用临时无梯度支路 `xW^T + scale*(xB)A^T`；原state_dict不变。具体层、rank和幅度随用户选信号后再定。

### 输入/内部量边界

- teacher/student共享冻结VLM，单读这个共同前缀会得到相同特征；想比较两边学习状态，应读各自动作专家或比较它们对同一前缀扰动的输出响应。
- 学生只在t=1学习端点映射；中间t速度查询、多步重建残差或CNF似然不是已验证的学生行为，暂不作U_S。
- 不能把GEO/DV的缺测补零。特征/时序信号缺测时应有valid标记和明确退化规则。

## 3. 动作级加权：改变“这批数据里重点学哪里”

目标方向为D高、U_T低、U_S高。参考LLKD/DWA-KD的师生可靠性方向、PIVOT-Q的动作差异和UACD的局部监督思想，**具体连续动作公式是我们的设计**。

建议先采用幅度温和、能退回Direct的候选，而非直接把三个原始值相乘：

```text
rD,rS,rT = 各自转换成同任务的历史分位数（0～1，平值用中位秩）
w0 = 1 + (rD + rS - rT - 0.5)/3       # 0.5～1.5
w = w0 / mean(w0)                    # 平均权重1
L = mean_i,h[ stop_gradient(w_ih) * MSE14_ih ]
```

系数1/3是我们为首轮控制扰动幅度提出的工程选择，不来自论文最优值；应比较权重恒1、D-only、加入老师/学生信号。历史分位数避免用多个不同单位相乘；先看各动作位置的分布，防止权重仅重现“块尾天然更大”。不先强制逐位置归一化而抹掉真正阶段差异。

D本身就是MSE的平方根；原损失已更关注大误差。若再无界乘D或D²，容易让少数异常样本主导。权重均值归一可减少整体步幅漂移，但仍需记录加权前后梯度/裁剪率。低U_T并非一定正确，权重设计不应把低分样本彻底丢掉。

## 4. 优先动作块抽样：改变“下一批多看到谁”

保留任务均衡：先按现有概率选任务，再在任务内按窗口priority抽样；不能让长任务重新获得更多总预算。

候选priority为上一次该窗口的 `mean_h(w*error)`，记录更新步。优先抽样从50%原均衡抽样＋50%priority混合开始，保留覆盖机会。混合比例是待验证工程选择。新/未访问窗口用统一初始priority，第一次访问后更新；优先数组只存ID、分数和更新时间，不缓存完整图像/动作老师答案。

**避免同一分数被无意放大两次：**若抽中概率和loss权重都按同一分数增加，实际重点是二者乘积。若希望优先抽样只提高取样效率、仍优化上节定义的目标，需使用抽样时的校正因子：

`L_sampled = mean[(P0(i)/Pdraw(i)) * mean_h(w*error)]`

这是PER的重要性采样思想，校正抽样偏差后动作权重w仍存在，不会把有意加权取消。50%均匀混合使P0/P≤2（任务内），避免极稀少样本的巨大校正。归一/分位数统计若随当前batch变化，只能把上述理解为条件于冻结评分的目标；实际需用历史统计并记录版本，不声称训练过程严格无偏。

实现需让decoded_batches透传window_id、task_id、draw_probability；DDP合并本轮少量ID/priority更新；预取队列保存“抽取当时”概率。续训小状态包括priority、更新时间、抽样RNG和评分归一统计。约42.7万窗口的一列float32仅约1.6MiB，不需要新建大回放。

首轮先做权重模块，再做抽样消融；这不是取消GAD抽样部分，而是把两者贡献分开验证。无需改模拟器或追加在线RL。

## 5. 成本与扩展

Direct本来就每批推老师和学生。若老师N10、学生N1，原动作专家调用量约11；K4两边完整重算约44。它不是整步耗时的精确4倍，视觉前缀、反向和供数也占时。扰动VLM还需重算前缀；只扰动专家可复用前缀，但信号质量可能不同。

先测少量固定窗口的候选信号，再决定K与刷新频率。不得把其它模型论文的32ms/50倍直接套到我们的π0.5。报告等更新数与等wall-clock两种曲线；若额外信号耗时抵消收益，就不能称训练效率提升。

CP/DMD/MFD未来复用信号接口，但不是一个乘号就完成理论迁移：CP的目标由EMA/相邻流时间构造；DMD/MFD是分布指导。先明确被加权的学生动作目标，保持辅助网络训练原样。DMD原本未必生成多步老师终点，加入D信号会额外增加教师前向，不能称免费。
