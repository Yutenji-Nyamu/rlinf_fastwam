## 本轮收敛

- 一步学生没有可供比较的连续去噪速度，原 GEO/DV 对它是**未定义**，不是零。保留为多步老师诊断，不强行充当师生共用信号。
- 独立选择三个量：师生动作分歧 D、老师不确定性 U_T、学生不确定性 U_S；再独立决定动作权重与动作块采样。信号与调度不能混为一项。
- 本次回到原始四噪声定义；参数扰动、输入扰动、覆盖度等仅作后续研究。
- 用户授权Direct、DMD new、MFD、CP v2同时加入动作加权与优先抽样；保留各自模型/方法/预算，单独实验目录。信号公式、梯度位置、采样校正与每项参数来源见09。
- 0.5～1.5权重、50%均匀抽样为中等幅度适配，不标成文献或历史已验证最优值。
- 跨领域新增：TFB/TokUR/SWAG解释模型扰动，SPUQ/TTA解释输入扰动，BootsTAP/UFlow解释一致性筛选，KNN/PatchCore/DDU/HyperDUM解释特征覆盖，UA-MT直接对应可靠教师监督。近期正式会议与经典方法分开标注；源码审阅发现的适配限制见07。
