# 后续绘图流程

1. 从episode索引选原生成功且视频/信号齐全的轨迹，优先有多个独立成功例子的任务。
2. 读取每query的逐动作U，按实际执行h连接；未执行的chunk尾部不得画成已执行信号。
3. 查找峰值、谷值和阶段变化，再由同一episode/frame-map定位三相机真实帧。先看视频与帧，再做说明，不用等间隔截图冒充峰值。
4. 图注保留任务、模型训练seed、episode ID、真实layout seed/编号/repeat、运行ID、query/h、frame、控制tick与相机；多个失败/成功例子并列才有解释价值。
5. 保存可重算的端点/噪声、归一化坐标约定、输入观察、最终动作和结果。图表静态导出用SVG/PDF；视频与大NPZ留服务器，源码/轻量索引与日志推Git。

U不是失败概率；成功轨迹也可有高U。图形清晰度筛选与统计评估分开，候选素材数量不足如实标明。
