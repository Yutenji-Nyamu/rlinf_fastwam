# Dojo现场与实现计划

深圳3已有已跑通RoboDojo与官方Pi_05 JAX策略（Dojo 50aab2b，XPolicyLab 10ab265），三seed模型和资产已安装。深圳1后续N25评估为6dddac8；历史显示普通N25可推进，但random N25出现初始化设备故障，不将其归为已根治。复用单worker、原生动作/相机/插值和已验收图形绑定；不引入RLinf Robotwin模型或重写Dojo控制器。

Dojo原生保存三路25fps连续录像；每个joint模型动作再由原生控制器插值到物理步。本次补相同观察/噪声M10/M5端点U、每query输入与动作、query/h/布局/视频帧/控制tick映射。保留官方M10动作返回与JAX RNG演进，M5只做旁路。先对真实第一query做一次动作/RNG一致性核验。

资源：本轮空卡授权，优先深圳3·3做smoke；正式深圳3·6/7等待当前CP180阈值扫描结束，再Dojo，最后逐卡RLT。保留原候补配置和CP250/250，其他五组EXPO不动。

采样：覆盖54个官方配置，复用已运行的N25并行，每任务5批×25＝125回合，共6750回合；这是用户“约128、取并行整数倍”的最新预算。取消成功够12条即停止及零成功小预算初筛。每任务选历史较好官方训练seed，成功与失败全部保存，再推荐最多12条绘图候选。模型M10/H50及动作控制不变；这是绘图素材采集，任务间模型seed不同，不作为统一benchmark表。

布局：已有三组布局seed，每组每任务30–75份。按布局编号、seed0/1/2轮流取已有文件，先遍历不同文件，数量不足125则循环并标repeat。回合ID独立0–124，元数据另存真实layout seed、原文件编号与路径；Policy的随机流随回合继续，M10/M5共享本次噪声。不能把125次轨迹说成125个不同布局。只在私有入口覆盖原25/50预算和random并行上限，原生布局加载、动作、相机与成功判断复用。

异常：初始化或持续无动作进展超过既定等待限额时跳过，已完成回合留存并报告实际数量；精确清理本轮子进程后换任务。正式任务由125回合和原生每回合动作上限约束，不另加3小时硬截断，避免正常五批采集被提前结束。GPU设备故障或无法清场则停本卡并记录，不reset共享GPU或盲目重复。smoke完成真实视频/U/绑定验收后才开放正式队列。
