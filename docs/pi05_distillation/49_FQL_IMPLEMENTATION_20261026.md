# FQL实现：固定π0.5老师，多任务一步学生

2026-10-26。**已实现并通过CPU检查；按用户最新指令，未占GPU、未采真实数据、未做GPU smoke、未开始正式训练。** 本页接续46–48号规划。

## 这版做什么

从已跑通的直接10→1蒸馏分支增加共享任务条件双Q。老师和视觉语言部分冻结，学生动作专家与Q训练。学生目标是 `10 × H50端点MSE − 双Q平均值`；Q评价实际提交的前C10个动作，用下一观察的一步学生动作构造目标。

它是固定π0.5行为先验的FQL适配：原FQL还训练多步行为模型的FM项，本版按已有规划固定老师，不增加专家动作FM、不采用EXPO的Editor/温度机制。

## 实现与依据

|部分|实现|依据|
|---|---|---|
|基座|Sidney π0.5、三相机、绝对关节、原归一化，H50/C10、老师N10、学生N1|当前1·45直接蒸馏实际配置|
|训练模块|共享冻结VLM与前缀缓存，仅训学生动作专家；新共享双Q|已验收Velocity与endpoint路径；46号方案|
|Q输入|带mask池化的VLM特征、归一化14维关节、C10动作＋动作mask＋剩余预算比例|多任务指令在VLM特征中；有限时域宏动作适配|
|Q网络|两套4×512 MLP，GELU→LayerNorm；Xavier初始化|官方FQL `Value/MLP`，LayerNorm eps=1e-6|
|Q参数|Adam 3e-4，目标更新tau=.005，两头mean，gamma=.99/决策|官方FQL默认；决策时间尺度由本项目明确|
|学生参数|AdamW 2.5e-5、betas(.9,.95)、wd1e-10、clip1、暖启动＋余弦|继承当前成功直接蒸馏；新数据量确定后重算时间表|
|损失权重|alpha=10，不做额外Q幅值归一化|官方默认起点；是否适合需真实smoke/训练诊断|
|batch候选|全局384，每卡192；支持单卡累积或双卡DDP|继承直接蒸馏；新增下一观察处理后容量尚未验证|
|数据抽样|先均衡任务，再自然抽任务内转移|复用BalancedWindows的无隐状态抽样逻辑；不强制成功/失败各半|

算法核对：[官方FQL损失与默认参数](https://github.com/seohongpark/fql/blob/e8cd16eb490332924dfa2492097219f181765933/agents/fql.py)、[官方Q网络](https://github.com/seohongpark/fql/blob/e8cd16eb490332924dfa2492097219f181765933/utils/networks.py)、[ReinFlow PyTorch参照](https://github.com/ReinFlow/ReinFlow/blob/e722e151bed767f3ffef47527cf697f2358af55d/model/flow/ft_baselines/fql.py)。本轮重新读取官方源码，ReinFlow复用10月25日固定版本归档。

与46号草案有一处细化：Q和学生的损失都使用本轮更新前的Q，分别累积梯度后各更新一次，随后软更新目标Q。这与官方联合更新的参数快照一致，避免因微批不同改变更新顺序。Q参数在actor反传时冻结，但对动作的导数保留。Q目标与老师目标全部无梯度。两项动作梯度RMS只在首个微批诊断，不额外反传完整模型。

## 文件切口

- `rlinf/algorithms/pi05_distillation/fql.py`：双Q、目标Q更新、Bellman目标及学生目标。
- `model.py::prepare_fql`：复用原生观察处理与一次VLM前缀计算，旧prepare保持。
- `transitions.py`：每回合HDF5写入、完整回合索引、任务均衡读取；相邻转移共享T+1观察。
- `tools/pi05_policy_eval/run_batch.py`：只在collect_transitions开启时捕获原生整块C10返回。不开开关时维持旧评估；不拆成单步。
- `tools/pi05_distillation/train_fql.py`：独立训练入口、单/双卡、全局batch累积、完整恢复与学生导出。
- `fql_prepare.py/fql_index.py`：从当前实配准备任务与种子，采完按真实转移数量生成训练预算。

## 数据保存

保存当前/下一RGB和关节、实际指令、全局task_id、请求/实际种子、原生重试、H50归一化预测、C10绝对/归一化指令、mask、原生奖励/终止、首次成功奖励、剩余预算和噪声种子。不开视频、U、四噪声、Attn和逐物理步日志。

首版保留**评估器原始决策边界RGB**，在读取后走同一个原生预处理；不自行重缩放图像。这使落盘前后输入可精确比对，但不能直接沿用100GiB的224×224容量估计，真实容量待smoke。

成功、官方预算正常失败均有效；异常/未完成文件保留.partial且不进入索引。成功只记一次奖励，成功或官方上限末块bootstrap=0；意外提前终止不伪装成失败样本。真实种子重复及已知评估种子重合会被拒绝。准备器读取当前评估种子表和已有实际种子；尚未建立完整HF原始种子排除表，不能声称已验证与全部预训练数据无交集。
