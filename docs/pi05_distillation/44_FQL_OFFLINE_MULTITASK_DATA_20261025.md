# FQL：离线、多任务与真实数据核对

2026-10-25。仅研究规划，未启动FQL。当前模型、训练队列和评估协议保持。来源与另一实现详见[45号](45_FQL_MULTITASK_REFERENCES_REINFLOW_20261025.md)。

## 先回答问题

FQL可以完全离线：从已经保存的数据学习，不必边学边让机器人执行。Q也从这些数据学习；数据要有即时奖励，但不需要有人先标出Q值。Q估计“现在这样做，后续累计能拿多少奖励”，利用下一观察的价值逐步把结局向前传。

FQL也能扩展到offline-to-online；这不改变它能离线训练的事实。原论文和官方入口按环境/任务分别训练，73个基准任务不等于一套联合73任务模型。原版同时训练行为流B、一步策略G、双Q；用户讨论的冻结B、只训练G和Q属于明确的固定先验适配。

## 多任务用几个Q

首候选是**一套共享、带任务条件的双Q**：输入包含图像、关节状态、任务指令和动作块，输出两个回报估计。所有50任务共享参数，每个batch均衡取任务。双Q是两个估计器用于稳定学习，不是两个任务；另有慢更新的目标副本，用于提供较稳定的训练目标。

同样一幅画面，“把碗叠起来”和“把碗分开”的好动作不同，所以Q必须知道任务。不能原样复用当前EXPO只看图像、关节、动作的单任务Q。若以后证实任务干扰严重，再考虑共享主干＋任务头；没有依据先建50套独立Q。

## 冻结10步老师时，一次更新具体做什么

这里“一次”指一次参数更新，不是一次机器人回合，也不是扫完全部数据。

1. **取真实记录**：均衡选任务，抽一批“当时看到什么、执行哪一段动作、得到什么奖励、之后看到什么、是否结束”。当前与下一观察都来自同一真实示范/历史执行。
2. **教Q算账**：一步学生给下一观察生成一个候选动作，不送进模拟器；慢更新Q评价它。用“本段奖励＋折扣后的下一段价值”作为目标，训练Q对数据里真实执行的动作打分。下一动作生成及目标值都不回传梯度。
3. **教学生选动作**：给老师和学生相同的当前观察、指令、初始噪声。老师算10步，固定输出作为参照；学生算1步。学生既减少与老师动作的差距，又让自己的动作获得更高Q值。此时Q参数不更新，但保留Q对动作的导数，才能把“动作往哪改”传给学生。
4. **慢慢更新目标Q**，记录损失、回报估计、动作偏离和逐任务采样量。随后重复取数据；部署仅用一步学生，老师与Q都不用运行。

直观式：`学生损失 = α × 同噪声端点动作差距 − Q(学生动作)`。

老师始终冻结，故没有本轮老师FM更新；这与原版FQL的B持续行为克隆不同。也不需要提前缓存大量老师10步答案：训练时即算即可。Q不是可靠的成功率百分数，奖励与折扣都会改变其数值。

## 本轮实际检查了什么

正在使用的HF数据固定版本：`TianxingChen/RoboTwin2.0@9dc9299c163db059931898a9f0852098a61155a1`。2500条Clean示范、50任务；当前蒸馏窗口427287个。没有切到HF最新版本。

- 检查全部50任务的`meta/info.json`：特征一致，均没有reward、done、terminated、success字段。
- 实读调瓶子、按铃、叠碗的Parquet首尾记录：有三相机图像、关节、动作、时间、轨迹号、帧号和指令索引。
- 实读本地按铃原始zip内episode0.hdf5：81帧，包含RGB、相机标定、`joint_action`、末端姿态；HDF5没有奖励或成功标签。zip另有seed、场景信息、指令和专家轨迹文件。
- 检查固定版本官方转换源码：观察采用第t帧，动作目标采用第t+1帧关节位置；最后一帧观察不写入转换数据。
- 对按铃原始HDF5和已用Parquet逐值比对：81原始帧→80行；state对原始t、action对原始t+1最大差均约2.73e-8（浮点精度）。这是一条真实样本的时序验证，不冒充2500条全验。

官方收集器确实有专家成功筛选和采集后成功断言，支持这些是成功示范的来源判断；但当前main与我们的旧HF版本不能直接画等号，且它不提供每帧首次成功时间。规划应明确采用“经确认成功轨迹的终点奖励”，不能声称恢复了原环境全部逐步奖励。

已核的原始按铃包仍在；叠碗prepared.json记录的旧下载包路径本轮不存在，转换数据仍在。因此不是“所有原始包都已核可用”。需要补齐原始尾帧时可定向找回该固定版本，不必重采2500条。

## 与我们H50/C10接口的关系

学生仍输出50个动作，蒸馏可保持H50；Q评价真实执行的前10个。下一观察必须对应执行这10个动作之后，不能误接H50之后。末块不足10步时记录k及动作mask，不能让填充动作影响Q。

若γ按每个物理动作定义，目标应是`段内折扣奖励 + γ^k × 继续标记 × 下一Q`；若按决策块定义，则记录另一套一致口径。不能混用。旧EXPO的`discounted_chunk_return/chunk_td_target`可复用公式，不能连同Editor/熵温度/20次Q更新一并搬入。

## 成功示范够不够

从格式上，经上述补齐可以做“仅专家示范的离线FQL”；不是必须先新采模型推理数据。

从学习信息上，只有成功路线上发生过的动作，Q缺少失败与偏离路线的真实证据。学生会试着提高Q，可能利用Q在陌生动作上的误判；端点蒸馏能约束偏离，但不能保证解决。这也是纯蒸馏和加Q必须分别报告的信息预算。

建议优先查已有成功＋失败的真实转移是否仍留存；当前精简评估只留成绩，不能把“成功率CSV”直接作为Q训练数据。若确实缺失，再单独决定小规模固定种子的转移采集。本轮不新增采集。

## 收敛方案与证据路径

先选固定老师、多任务共享双Q、现有一步动作专家这一个切口；最先落实数据转移和终点奖励定义。数据确认之后再决定Q预热/α量级/容量，不照抄小MLP的学习率或直接承诺每卡192。保留原始N1/N10以及直接蒸馏作为同协议对照。
