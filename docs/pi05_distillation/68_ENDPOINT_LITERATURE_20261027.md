# 直接蒸馏是否只能做低性能对照：文献与代码

2026-10-27。配合[67号现场审计](67_ENDPOINT_CONVERGENCE_AUDIT_20261027.md)。区分纯端点MSE、路径一致性、分布匹配与专家监督，不将“一步”统称同一方法。

## 结论

直接多步→一步回归是有依据的方法，也常作为参照或其他算法的组成部分。查到的材料不足以支持“通常一定不能恢复老师”这种跨模型、跨任务判断。图像领域有明确回归单项弱于组合目标的消融；机器人领域也有一步匹配甚至超过老师的报告，但往往增加了别的训练信号。

我们的损失把观察和噪声都交给学生，同一个(o,z)有确定老师答案T10(o,z)。所以不能直接套用“把同一观察下多种动作求平均必然塌缩”的论断。在足够表达能力与覆盖下，它是在学一个确定映射；实际有限网络的一次计算能否拟合十次复合计算、关键状态是否覆盖、误差是否影响闭环，都需实验。

## 为什么loss继续下降，成功率仍可能平台

损失是“整块每个数像不像老师”的平均；任务成功是“经过多次观察/执行，是否完成”。两者之间隔着执行段截取、动作反归一化、仿真动力学、接触/夹爪事件和下一次观察。

例如，后40个计划动作更接近老师会降低H50损失，但机器人本次只执行前10个；又例如接近物体阶段许多小误差下降，抓取瞬间仍差一点，整条回合仍失败。这些机制合理，不能未做分项诊断便断言哪个正在主导。

多步老师每步可根据当前内部动作重新修正；一步学生需要一次完成这段复杂映射。同架构、相同参数量不等于相同计算能力，也不意味着数学上永远不可拟合。我们的优化结果应与数据覆盖及计算预算共同解释。

## 对本项目的判断

纯终点蒸馏当前从20.38%提高到31.25%，说明学到了有用能力；仍落后老师41.58%，说明目前未恢复完整闭环表现。这个结果既不是“完全失败”，也不足以当成直接蒸馏的固有上限。

最值得优先处理的是67号发现的末段观察覆盖，以及固定观察上的前10误差诊断。增加专家FM、学生状态再标注、分布匹配或一致性都属于另一个训练目标/数据条件，应单独命名比较。学习率大小应靠实际更新及对照判断，不能因为一种目标接近成功就机械复制给另一种。
