## 复用边界

以已验收 `0fd7dcf11` 为起点，新增独立 `method=mfd`。保留旧OneDP函数与配置，独立配置与现有方法并存。主要改动限 `rlinf/algorithms/pi05_distillation/losses.py`、`tools/pi05_distillation/train.py` 和独立配置；保存/导出沿用已有接口。

保持同一Sidney基座、原归一化、三相机、绝对14维动作、H50×32模型输出；VLM和老师冻结，仅训练学生/辅助动作专家。积分仍在完整32维里进行，最终学生目标只计14维。前缀KV在同批所有查询之间复用。

数据仍是Clean50×50任务的观察、状态、指令，任务均衡抽样。学生动作即时生成；不需要先缓存老师终点，不需要FQL正在收集的奖励和失败转移，也不把HF专家动作增加成学生监督项。

## 最小方法实现

用π0.5时间约定：1=噪声，0=干净动作。令 `a=G(z,o)`，重新采样噪声 `eps`，选 `0<=r<t<=1`：

```text
x_t = (1-t)*a + t*eps
无梯度：
    x_r_T = Euler(T, x_t, t→r, 同一观察前缀)
    x_r_F = Euler(F, x_t, t→r, 同一观察前缀)
    u_T = (x_t-x_r_T)/(t-r)
    u_F = (x_t-x_r_F)/(t-r)
    direction = u_T-u_F
student_loss = mean(stop_grad(direction[..., :14]) * x_t[..., :14])
```

这样只通过 `x_t→a→G` 反传，不穿过两条积分路径。辅助单独用 `MSE(F(x_t,t), eps-a.detach())`；五次辅助各重新生成学生样本、换噪声，观察前缀复用。

计算平均速度时优先累加 FP32 `dt*velocity` 再除以区间长度，避免BF16两个相近端点相减丢精度。两条轨迹仍按各自当前状态前进。等时间退化到瞬时速度；不直接除以零，也不擅自裁掉短区间。

不加判别器、EMA学生、Q、CFG、双时间网络或JVP。π0.5原始老师不使用SANA的CFG=4.5。

## 并行与积分成本

官方batch=1的积分循环不能整段照搬。最新合批方案见[64号再次收敛](64_MFD_REFINED_PLAN_20261026.md)：两卡各192，共用积分步数、档内各样本分别采时间。此处早期“全批共用一对区间端点”只保留为短验收失败时的简洁备选；两种方案都不将192个样本逐个推理。

公开代码默认最大Euler步长0.02。两个均匀时间之差平均为1/3，所以每条路径平均约17次前向，最多50次；老师＋辅助合计约34次，当前DMD指导只有2次。增加的是动作专家无梯度前向，不重复跑VLM，也不保留这些步骤的反向图。

优先照0.02做短计时，再试0.05只作为明确的计算成本对照；0.05不是论文最优参数。正式选择需要看到实测速度和指导方向变化，不能凭“平均更稳”直接承诺收益。现有6.02秒/步不能用于MFD ETA。

## 短验收，先验证什么

1. 恒定速度场能积分到已知终点；T=F时指导为零；时间方向和梯度符号用一维可解析例子核对。
2. 单次Euler退化与瞬时速度一致；明确它与OneDP额外时间权重的区别；14维以外不进入学生计分。
3. 老师/辅助在学生更新时无梯度；辅助更新不回传学生；每轮实计5个辅助optimizer.step。
4. 两卡12步→保存→14步；导出原生N1；记录峰值、积分次数、每步分段耗时。已通过的供数和评估模块不重写、不反复验收。

新日志只增加对判断有用的少量量：区间长度、实际NFE、平均速度差RMS、真实/填充维辅助MSE、梯度范数、裁剪比例、积分耗时。线性指导loss可正可负，不能把它下降当成功率；最终仍看同协议任务成功率。

## 当前决策边界

代码切口清晰；主要不确定项是积分计算成本与策略效果。当前DMD new只有smoke结果，尚无全任务提升证据。建议实现后先短测即可，再按用户决策排正式任务。本轮不抢占FQL、直接蒸馏或其他用户卡。
