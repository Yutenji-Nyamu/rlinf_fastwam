# GAD-OT候选合同与后续验证

状态：2026-11-01规划，等待用户讨论后决定是否执行。

## 1. 通俗例子

同一场景可以左绕也可以右绕。老师两份答案是[-1,+1]，学生两份是[+0.9,-0.9]。

- 固定同编号配对，平均平方误差3.61。
- 交换两个老师的编号，平均平方误差0.01。

学生已经覆盖两种方向，差的是噪声编号和老师的对应关系。OT允许调整这张对应表。这个例子说明一种可能收益，不能证明当前机器人失败就是这种原因；同噪声蒸馏也不会必然把左右平均。

四噪声时不是做16次OT，而是算16个距离，再为整个4×4表求一份分配。K=4等份额一对一时共有24种排列。

## 2. 首选：均匀份额的完整动作块匹配

记每个观察的候选为S_i、T_j，均为H50×14；现有停止梯度动作权重为w_h。建议成本：

```text
C[i,j] = mean_h( w[h] × mean_d((S[i,h,d] - T[j,h,d])²) )
σ = argmin_排列 sum_i C[i,σ(i)]
L = mean_观察( IS × mean_i,h,d( w[h] × (S[i,h,d]-stopgrad(T[σ(i),h,d]))² ) )
```

IS为已有窗口抽样校正，每个观察一个正数，不参与匹配决策。用同一w构造成本和loss，保证选择的配对对应实际要优化的加权距离；若做纯OT对照则w=1。配对、权重和教师端点均停止梯度。

| 选择 | 建议起点 | 根据什么 |
|---|---|---|
| 老师/学生 | 当前N5/N1、冻结老师和VLM、训练动作专家 | 当前已跑通单任务Direct＋GAD |
| K | 两边各4 | 现有K4成本与信号定义；不是OptiFlow默认16/64 |
| 候选噪声 | 两边继续共用同四份噪声 | 便于保留旧信号和干净配对对照；官方OptiFlow两边独立采噪，属于明确适配 |
| 距离 | 整块、归一化真实14维、平方误差 | 当前Direct目标；OptiFlow以动作平方距离配对 |
| 份额 | 各1/4 | 没有独立候选质量评分，不改变老师经验分布 |
| 求解 | 24排列精确最小值；固定规则处理并列 | 均匀等数量平衡OT可取一个最优排列；K小可直接枚举 |
| GAD介入 | 原0.5～1.5权重、原50/50采样及校正 | 用户已选当前合同，不顺手提高介入强度 |
| 分歧D | 首版仍用原同噪声D；额外记录D_OT | 把配对改动与优先级定义改动分开 |
| 梯度 | 每观察随机一行重算并反传 | 减少激活；对照同样选行，有限集合目标含义见02 |
| 学习率/预算 | 继承对应Direct，不先放大 | 换配对后梯度可能缩小，先看真实幅度再讨论 |

## 3. Sinkhorn备选与它的代价

若想贴近OptiFlow，备选是对逐观察平均成本归一化，ε=0.05、30次log-domain Sinkhorn作为有原始出处的起点；需记录边缘份额残差。即使采用这两个数，K4和高维动作下也未验证合适。

需在两种损失间做明确选择：

1. **软运输加权全部配对距离**：公式直接，但一个学生同时被拉向多个老师，对平方误差而言其期望方向可能指向老师平均值。
2. **OptiFlow逐行argmax＋选中质量**：每行一个明确老师，但不是全局一对一；多个学生可能选同一老师，且总选中质量会改变loss尺度。

首版硬平衡匹配没有ε和选中质量缩放，更易看清“换配对”效果。不能把硬匹配叫作Sinkhorn实现；也不能把没有自运输扣除项的软OT叫作sDMD的Sinkhorn divergence。

## 4. GAD和OT可能互补，也可能目标有张力

- GAD当前大分歧可能包含“噪声编号不一致”的成分。OT降低它之后，再把D_OT用于优先级是另一项实验，不先混改。
- 教师候选分散可能表示多种正确解。GAD偏好教师集中，可能减少多模态场景的学习；这是应观察的机制，不是默认两者叠加更好。
- 匹配可以降低当前误差，却未必改善执行；它也可能让学生更容易模仿一个行为很弱的老师候选。
- K=4只有粗略的经验分布；如果每批配对剧烈变化，可能增加更新噪声。先看重配比例和梯度，再决定是否增加K或改软OT。

## 5. 后续最小顺序（尚未执行）

**先做有限的机制检查。** 固定少量真实训练观察，比较同噪声成本和最优配对成本、被重配的比例、动作块内容；历史N1/N5/N10信号来自原始模型，只能说明原始模型，不能冒充当前训练学生。

**再以Direct做两臂对照。** 两边都复用K4并同样抽一行重算；一边保持同编号配对，一边使用OT配对。这样与现有独立主噪声的GAD实现差异有明确控制。任务、老师、训练样本预算和评估种子一致。需要进一步分离GAD贡献时，扩成“是否GAD×是否OT”四格，而不是一开始铺开四种方法。

**随后才考虑DMD/MFD/CP。** 原核心损失不动，另增端点OT正则需要新系数，记录其相对原梯度强度。不能直接引用OptiFlow的λ=1，因为两边的损失单位与梯度尺度不同。sDMD的去偏方向可作为DMD专项设计参考，暂不新增判别器。

未来检查只覆盖必要项目：

- 4个老师等份额、无跨观察/时序配对；K=1退回端点MSE。
- 候选一致或仅排列时的配对结果；无teacher/权重/配对梯度。
- 当前低开销实现与四行平均的梯度估计含义一致；完整续训保留候选抽样随机状态。
- 记录原始/匹配MSE、重配比例、教师/学生标准差、梯度范数、更新耗时和峰值显存。
- 成效仍看同协议闭环成功率，并比较同更新数与同墙钟时间；不能只展示下降更快的OT误差。
