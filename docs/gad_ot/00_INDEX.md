用户已确认沿用现有GAD方向：师生差距大、老师较确定、学生较不确定。这里的“确定”由四噪声输出标准差近似，不等于已标定的正确概率。最新“先规划”优先于此前其他任务的执行授权。

## 一句话

GAD决定哪些动作多学；OT决定同一观察下，四个学生动作块分别向哪个教师动作块学。暂称 **GAD-OT**，具体属于“条件小批量最优传输端点蒸馏”。

## 建议先收敛的版本

- 以最近已验收的**单任务Direct＋GAD**为入口：原生adjust_bottle π0.5，老师N5、学生N1、H50/C50，真实14维；不是历史多任务N10/C10那组。
- 同一观察、状态、指令下复用已有四份噪声，得到师生各4个完整动作块；构造4×4距离表，解一个整体配对问题。
- 首版建议**等份额、整块一对一匹配**：每个老师候选用一次，四个学生各学一个；K=4只有24种排列，可以精确求最小总误差，无需新网络或Sinkhorn温度。
- 沿用GAD动作权重0.5～1.5、50%均匀＋50%优先抽样及原有概率校正；先保留同噪声分歧作权重来源，同时记录OT配对后的分歧，不一次改两处。
- 保留四噪声无梯度计算；只重算每个观察随机选中的一个学生样本来反传，避免四份动作专家计算图同时占显存。详细统计含义与对照要求见03。
- 这是借鉴OptiFlow配对思想的适配，**不是OptiFlow复现，也不是sDMD复现**。后续是否采用软Sinkhorn，单独比较。
