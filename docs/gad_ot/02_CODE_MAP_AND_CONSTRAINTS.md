# 现有GAD到OT：已核源码切口

读取基点：`2c378ec8bb557da42ccf26887f6217192884ef17`。本文件描述的是未来增量，不是已完成修改。

## 1. 目前一轮怎么走

数据窗口→复用冻结视觉语言前缀→GAD四噪声无梯度推理→得到动作权重/窗口优先级→原方法使用独立噪声做训练→更新优先级和保存状态。

代码：[`gad.py`](../../rlinf/algorithms/pi05_distillation/gad.py)、[`losses.py`](../../rlinf/algorithms/pi05_distillation/losses.py)、[`train.py`](../../tools/pi05_distillation/train.py)。

`observe()`按4次B大小前向处理，避免复制4份大的前缀KV。每次同一噪声分别生成学生N1、老师N5完整动作，再截真实14维；两组张量是`[B,4,50,14]`。独立随机数生成器不改变主训练随机流。

当前`action_weights()`计算：

```text
学生分散度 US[h] = 四个学生输出在位置h的总体标准差，再对14维取平均
老师分散度 UT[h] = 同理
师生分歧   D[h]  = 同噪声配对的14维RMSE，再对4对取平均
score[h] = (rank(D) + rank(US) + 1-rank(UT)) / 3
w[h] = 0.5 + rank(score)；窗口priority = mean_h(score)
```

rank在当前microbatch的B×H位置上计算并正确处理并列值，权重整体均值为1。原抽样是一半均匀、一半按优先级，另乘完整重要性校正。OT不再叠加一层候选“置信度权重”。

关键增量：当前函数只返回权重和小统计，**丢弃四份噪声及端点**。新增可选返回数据即可复用现有推理，不能为了OT再额外生成一套K4。

## 2. 哪些坐标可以重新配，哪些不能

- 同一个观察内，把完整H50×14动作块看作一个样本；只在K候选轴重新分配。
- 保持时间位置h与机器人动作维d的对应；不能把抓取前的动作配到抓取后。
- 不能每个动作位置各挑不同老师候选，拼成从未由老师生成过的整块计划。
- 不能跨观察、跨指令、跨任务配对，即使两个动作数值很接近。
- 距离使用现有模型归一化后的真实14维，内部32维生成保持；不新增[-1,1]截断或18维padding评分。

## 3. 一个容易犯的语义错误

四噪声的`UT[h]`是整个候选集合的离散程度，4个候选共享这个数。它不是每个老师候选各有一个可靠度。

因此不能直接把`softmax(-UT)`当作4个老师的非均匀份额；若把同一个量复制4次，仍是均匀份额；若改用“偏离均值的距离”，又会偏罚合法的少数动作模式。OptiFlow能给每个候选不同份额，是因为它额外有Q(s,a_j)。首版不引入Q，老师份额均匀，UT继续只影响原GAD的动作权重和抽样。

## 4. 四种基线不能机械替换同一种target

| 基线 | 当前真正比较的对象 | OT的干净候选位置 |
|---|---|---|
| Direct | 同噪声下，学生一步端点vs老师多步端点；`endpoint_loss()` | 可直接改端点配对，保持MSE、尺度和动作权重 |
| CP v2 | 相邻时刻桥接与EMA复合映射的一致性＋专家动作FM；`cp_loss()` | 可另加端点OT项；不能置换其时间桥目标后还声称原CP损失不变 |
| DMD new | 老师与辅助在含噪学生动作处的方向差形成带符号的代理梯度；`onedp_loss()` | 保留原方向项，另加OT指导；若借sDMD，需要明确去偏/门控及参数化适配 |
| MFD | 老师与辅助各自积分所得平均速度差；[`mfd.py`](../../rlinf/algorithms/pi05_distillation/mfd.py) | 保留积分目标，可另加端点OT指导；不能只换老师候选就等同原积分公式 |

现有GAD已对动作粒度损失加权；这不等于所有方法都有可以直接重排的“老师终点标签”。新增OT也不自动改动辅助网络的拟合目标。首版从Direct收敛，其他方法另做小设计。

## 5. 计算与显存

16个平方距离和4×4求解本身很小。真正昂贵的是策略前向和保留反传图。已有K4是no_grad，不能直接拿已有学生端点调用backward。

建议未来返回4份完整32维噪声、两组14维端点、权重及优先级。B=224时，这些FP32张量合计约10.3MiB；不包含模型、KV、激活及临时张量。不能把这点额外张量误称总训练显存开销。

每个观察均匀随机选一个学生候选I，用其噪声重做一次带梯度前向，监督为配对老师T[σ(I)]。在权重/配对停止梯度且重算前学生未更新的条件下，这是当前有限K集合平均配对损失的随机梯度估计；不等于无偏估计真实分布的Wasserstein距离。主训练独立噪声改为候选内噪声是实质调整，对照也必须用同一候选抽取流程。

Direct可能省去原主损失另做的N5老师前向，但尚未实测，不宣称净加速。若以后要四候选都参与反传，可顺序重算与累积，避免四图共存；它仍增加计算，不能当作免费复用。

| 位置 | 未来改动 | 保持 |

| `gad.observe` | 可选保留噪声和端点 | 四噪声定义、独立RNG、前缀复用 |

| `train.py` | 独立OT开关、候选行抽样、调用新损失 | 数据、优化器、训练预算、评估调度 |
| 配置/恢复点 | 保存配对模式和候选抽样RNG状态 | 完整续训、最新点滚动策略 |
