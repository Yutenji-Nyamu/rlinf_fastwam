为什么单条看得到，汇总却不明显？

12条成功轨迹逐条计算都是正相关，ρ约0.09～0.55；直接混在一起仅0.014。不同轨迹的距离基线不同，混合后会掩盖轨迹内部的变化。因此单条图、轨迹内分析与全体统计都要保留。

再看同一动作块：相关性更强，但一部分来自“预测得越往后，两条信号一起变化”。扣除块和块内位置的平均差异后，排名残差相关约0.161，不能把更高的块内数值直接解释为强预测能力。

补充检查去掉分母的绝对动作分散度，整体ρ为0.369，另3噪声版本为0.368。这提示相对/绝对尺度的选择有影响；它是探索性补充，不替换原指标。

蓝线是动作样本有多分散，橙线是师生意见有多不同。四个样本的分散度不等于严格概率熵；动作不同也不自动代表学生做错。

指标与材料

原分散度：每坐标4份输出的标准差÷4份输出RMS，再平均真实14维。补充绝对分散度：14维方差均值开根号。师生距离：同观察、同主噪声下，14维动作差的RMSE。所有量使用同一模型归一化坐标。
