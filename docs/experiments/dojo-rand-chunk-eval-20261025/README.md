## 有界尝试结果

- 采用：关闭视频/U/数组/逐动作落盘，原生每动作stdout也关闭，只保留5秒级心跳、成绩和错误。原生每动作物理推进及成功判断保持。
- 采用：同一JAX模型进程跨任务常驻。已经连续跑过3个短探针及完整任务开头，未重载权重；每次观察的instruction决定当前任务指令。
- 合批：两种实现均实际可运行，但N10和N1分别最大动作数值差0.01318、0.04257，未通过本轮同输入/同噪声atol=rtol=0.002检查，均使用逐环境推理。可能与低精度批尺寸数值变化有关，尚未证明根因；不等于Dojo底层不支持batch，也不说明合批成功率更差。本轮按用户要求停止追加调试。
- 只在决策时取图：观测调用从约100次降为2次，100动作探针总耗时214→142秒；但是首个观察的画面已有约0.46–0.49像素平均差、动作最大差0.071，不能把后续差异只归因于减传图。该A/B未建立等价，正式保留原路径。

短探针人为提前结束，原生success标记尚未终结，**任何PROBE的8/8不能解释为成功率**；正式总结明确排除PROBE，仅完整自然结束的回合计分。C10/N1两块短测试正常退出；C50/N10完整8回合已完成验收并自动进入216点队列。

时间依据：54配置原生步数上限合计43050，每条件平均797步；短测8环境的物理/观测约0.8秒/动作，N10整批推理约2秒、N1约0.3秒，任务初始化约90秒。全部跑到上限按此估约47小时，跨任务重置/失败跳过变化较大，先报2–3天，首批完整后校准。显存约29.7GiB，计算与图形均只在物理3卡；不是显存不足导致当前慢。
